# 帧智汇 · 近期修复验收需求（无限画布 / 爆款成片 / 我的素材）

## 一、测试说明（请先阅读）

- **被测系统**：帧智汇 Web 端（AI 视频 / 图片生成平台）。
- **登录方式**：打开 `/login`，点击「密码登录」标签，输入测试账号的手机号和密码，**勾选**「已经阅读并同意《用户协议》及《隐私政策》」后点击「登录」。不要使用「短信登录」（收不到验证码）。
- **费用红线（必须遵守）**：本次所有用例**都不得点击**以下按钮，否则会产生真实费用：
  - 无限画布节点编辑面板右下角的**生成按钮**（绿色、带价格的按钮，例如「约0.18元 ➤」）；
  - 爆款成片页面的「**去制作**」按钮；
  - 任何「确认并生成」「确认生成费用」类的确认框里的确认按钮。若意外弹出这类确认框，点击「取消」。
- **数据隔离**：无限画布相关用例一律**先新建一张画布**（名称以 `测试台-` 开头）并只在这张画布里操作，**不得修改、删除画布列表中已有的其他画布**。
- 页面布局按桌面浏览器、窗口宽度不少于 1366 像素来判断。

## 二、功能需求与验收标准

### R1 无限画布：节点右键「创建副本」有两个子选项（P0）

**背景**：需求 recvw1s5he1Vzy。对任意节点右键，「创建副本」需要提供子选项列表：只含当前节点 / 包含之前所有节点。

**操作步骤**
1. 登录后点击左侧边栏「无限画布」，点击「新建画布」，名称填 `测试台-复制测试`，进入画布。
2. 在画布空白处点击鼠标右键，在菜单的「添加节点」分组中点击「文本节点」。
3. 在新建的文本节点上点击鼠标右键，把鼠标悬停在菜单第一项「创建副本」上。

**预期结果**
- 「创建副本」右侧展开子菜单，子菜单中**同时**显示「只含当前节点」（右侧标注 Ctrl+D）和「包含之前所有节点」两项。
- 即使该节点没有任何连线（没有上游节点），两项也都必须显示。
- 点击「包含之前所有节点」后，画布上新增一个副本节点，页面出现「已复制 N 个节点及其连线」类成功提示。
- 点击「只含当前节点」后，画布上新增一个副本节点。

**异常场景**：靠近屏幕右边缘的节点右键时，子菜单应向左展开，不能被屏幕边缘遮挡。

### R2 无限画布：复制后粘贴到画布空白处，弹出二选一（P0）

**背景**：同需求 recvw1s5he1Vzy。用户按 Ctrl+C 复制节点后，在画布背景粘贴时，先弹出二选一小框。

**操作步骤**
1. 在 `测试台-复制测试` 画布中（或新建一张 `测试台-粘贴测试`），确保至少有一个文本节点。
2. 单击选中该节点（不要双击进入编辑），按 Ctrl+C。
3. 在画布上远离节点的空白处单击一下，按 Ctrl+V。
4. 在弹出的小框中点击「只含当前节点」。

**预期结果**
- 第 2 步后，页面顶部提示「已复制 1 个节点」。
- 第 3 步后，出现标题为「粘贴哪些节点？」的小框，包含「只含当前节点」「包含之前所有节点」两个选项，每项右侧标注节点数量（如「1 个」）。
- 第 4 步后小框关闭，画布上新增一个节点。

**异常场景**：小框出现后点击框外任意位置，小框关闭且**不粘贴**任何节点（节点数量不变）。

### R3 无限画布：新建视频节点默认画面比例 9:16（P0）

**背景**：投放以竖屏为主，生成的视频经常不是 9:16，需要后期手动拉伸。

**操作步骤**
1. 新建画布 `测试台-比例测试` 并进入。
2. 画布空白处右键 →「添加节点」→「视频节点」，单击该节点，下方出现编辑面板。
3. 在编辑面板底部的模型按钮中选择「Framora 1.0」（没有则选任一支持 9:16 的视频模型）。
4. 点击模型按钮右侧的参数按钮，展开参数菜单查看后，按 Esc 关闭。**不要点击生成按钮。**

**预期结果**
- 参数按钮的文字中包含「9:16」。
- 参数菜单「画面比例」一组中，当前选中（高亮）的是「9:16」。

### R4 无限画布：图片节点参数文案带单位（P2）

**操作步骤**
1. 新建画布 `测试台-参数文案` 并进入；空白处右键 →「添加节点」→「图片节点」，单击该节点打开编辑面板。
2. 查看模型按钮右侧的参数按钮文字；点击它展开参数菜单查看，再按 Esc 关闭。
3. 在模型按钮中切换为「Seedream 5.0」（若没有该模型则跳过本步），重复第 2 步。**不要点击生成按钮。**

**预期结果**
- 生成数量显示带「张」，例如「1:1 · 1张」，而不是单独的数字「1」。
- 若有「分辨率」参数：纯数字档位带单位（如「512P」「720P」），K 档显示为大写（如「2K」）。
- 若有「水印」参数：显示为「有水印 / 无水印」，而不是「开 / 关」。

### R5 爆款成片：输入框中 @图片 引用按 Backspace 两步删除（P1）

**操作步骤**
1. 登录后点击左侧边栏「爆款成片」，停留在「制作视频」标签页。
2. 点击大输入框，输入：`把 @图片1 放到海边`（「@图片1」后面有一个空格）。
3. 把光标放在「@图片1 」后的空格之后（即「放到」之前），按一次 Backspace。
4. 光标不动，再按一次 Backspace。

**预期结果**
- 第 2 步后，「@图片1」以绿色高亮显示。
- 第 3 步后只删除了一个空格，内容变为：`把 @图片1放到海边`。
- 第 4 步后整个「@图片1」被一次删除，内容变为：`把 放到海边`；不得出现「@图片」「@图」这类逐字残留。

**范围**：爆款成片输入框、制作图片对话输入框、无限画布节点提示词框，三处行为一致（至少验证爆款成片输入框）。

### R6 爆款成片：视频模型列表 Framora 排在最前（P1）

**操作步骤**
1. 进入「爆款成片」→「制作视频」。
2. 点击输入框下方工具条最左侧的视频模型按钮（显示「请选择视频模型」或当前模型名）。
3. 查看后按 Esc 或点击空白处关闭，**不要选择模型、不要点击「去制作」**。

**预期结果**：弹出的「视频生成模型」列表中，第一个模型是 Framora 系列（如「Framora 1.0」），排在 HappyHorse、万相等其他模型之前。

### R7 爆款成片：输入框工具条一行排开（P2）

**操作步骤**：进入「爆款成片」→「制作视频」，浏览器窗口宽度不少于 1366 像素。

**预期结果**
- 输入框下方工具条中，视频模型按钮、参数按钮（显示比例和时长）、「@」按钮、「爆款脚本自动生成」下拉，四个控件位于**同一行**，「爆款脚本自动生成」不会被单独挤到第二行。
- 同一行右侧依次是「操作教程」、麦克风按钮、「去制作」按钮，与左侧控件不重叠。

### R8 我的素材：视频预览自动播放，左右切换到视频也自动播放（P1）

**前提**：测试账号的「我的素材」中至少有两条视频。没有则将本条标记为缺少条件，不要上传新素材。

**操作步骤**
1. 点击左侧边栏「我的素材」，在类型筛选中点击「视频」。
2. 鼠标悬停在第一个视频卡片上，点击「播放」。
3. 等待约 5 秒，观察播放器时间。
4. 点击预览层右侧的「下一个」箭头切换素材（遇到图片继续点，直到切到视频），等待约 5 秒。
5. 点击播放器控制条上的暂停按钮。

**预期结果**
- 第 3 步：无需手动点击播放，视频自动开始播放，播放时间从 0:00 开始增加。
- 第 4 步：切换到的视频同样自动开始播放。
- 第 5 步：视频暂停，播放时间停止变化（仍可手动暂停 / 继续）。

### R9 爆款成片 · 制作图片：费用前后一致（P1，只读核对）

**操作步骤**
1. 进入「爆款成片」→ 切换到「制作图片」标签页。
2. 在输入框中输入：`一只橘猫戴着透明宇航员头盔，置身赛博朋克城市夜景`，选择任意图片模型，等待「去制作」按钮左侧出现价格（如「约0.18元」），记下该价格。
3. 点击「去制作」，弹出「确认生成图片」确认框后，读出框内「预计费用共 约X元（每张约Y元）」，**然后立即点击「取消」**，不得点击「确认并生成」。

**预期结果**：确认框中的合计费用与第 2 步按钮旁显示的价格**一致**；金额显示不低于实际（向上取到分，不四舍五入）。

> 注意：本条第 3 步会打开付费确认框，执行时**只能点击「取消」**。如果测试账号积分不足导致直接弹出「积分不足」框，同样点击「暂不生成」并将本条标记为缺少条件。

## 三、不在本次范围

- 任何真正发起 AI 生成的流程（图片生成结果卡片、生成中占位比例、视频时间轴拖拽等需要先生成内容的功能）。
- 全屏视频时空格键行为（需要真人手势进入全屏，自动化无法稳定触发）。
- 登录页切换标签时的画面闪烁（属视觉过渡效果，难以用断言判断）。
