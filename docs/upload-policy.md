# 上传规则（2026-11-16）

后端签发的上传 URL 不再限定存储域名，通用素材、T+5 和剧本附件共用 URL 格式校验，不依赖开发/生产模式或 VITE_ZZH_ALLOWED_UPLOAD_ORIGINS。只发送存储表单，不带业务 Cookie，禁止自动跳转。

T+5 素材没有格式、单文件大小、总大小、数量或至少三份实拍要求，可以不上传直接下单。空 MIME 以 application/octet-stream 请求凭证。后端返回旧限制字段为空数组/0 表示不限，前端不再用它们拦截。存储服务和浏览器仍可能返回自身错误，按实际错误显示。

未完成上传仍需完成或删除，提交后的素材归属和只读校验保留；无素材以提交日计算 T+5。权限、积分、退款和返工规则不变。
