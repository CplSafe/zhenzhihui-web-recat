## 2. 背景与目标

本期主要完善以下产品能力：

1. 无限画布的节点创建、连接、快捷键、素材选择、生成参数、多结果展示、错误详情和任务恢复。
2. 爆款成片、爆款复刻入口的模型选择、参数选择、`@` 素材引用和脚本选择交互。
3. 图片及视频生成前的素材有效性、团队归属、任务类型和视频时长校验。
4. 视频预览、进度拖动、下载和全屏空间计算。
5. AI 文案辅助的连续改写和逐步复原。
6. 任务中心、素材跳转、团队入口、个人数据统计与积分展示。
7. 音频节点底层兼容代码保留，但当前产品入口关闭，不向用户展示。

自动化测试目标：

- 验证正常流程可以完成。
- 验证非法输入在提交和扣费前被阻止。
- 验证刷新、切换项目或切换团队后状态不会串写。
- 验证不同角色看到正确的入口和数据。
- 验证前端展示与实际请求参数一致。
- 验证当前关闭的音频功能不会从任何用户入口出现，也不影响图片、视频和文本节点。

## 4. 测试数据与执行约束

### 4.1 固定测试素材

- 横图：16:9，JPG 或 PNG，小于 5 MB。
- 竖图：9:16，JPG 或 PNG，小于 5 MB。
- 短视频：5 秒，MP4，可被浏览器正常 seek。
- 边界视频：30 秒。
- 超限视频：30.2 秒或 31 秒。
- 跨团队图片：属于另一个测试工作空间。
- 失效素材：已删除或后端明确返回不可用的素材 ID。

### 4.2 数据命名

自动创建的数据统一使用：

```text
AUTO_TEST_{日期}_{用例编号}_{随机串}
```

测试只能清理具有 `AUTO_TEST_` 前缀且由当前执行创建的数据，不得删除用户已有项目、画布、素材、视频或团队。

### 4.3 生成与扣费约束

- 无消耗测试不得点击最终生成按钮。
- 真实生成测试必须使用账号 D，并在任务开始前记录积分余额。
- 单轮真实生成建议预算不超过 20 元等值积分，具体上限由测试负责人配置。
- 每次生成记录预估积分、提交参数、任务 ID、最终状态和实际扣费。
- AI 输出具有随机性，不对具体人物、文案或像素做完全相等断言。
- 图片和视频生成超时建议设置为 15 分钟；超时应标记为阻塞或失败，不得自动重复扣费。

## 5. 功能需求与验收标准

## 5.1 无限画布基础操作

### CANVAS-001 创建并进入画布

**前置条件**：用户已登录并进入“无限画布”。

**步骤**：

1. 新建画布，名称使用测试前缀。
2. 进入新建画布。
3. 刷新页面。

**预期结果**：

- 画布创建成功并可打开。
- 刷新后仍停留在同一画布，已有内容不会丢失。
- 保存状态不会长期停留在“等待保存”。

### CANVAS-002 节点创建与重复连接

**步骤**：

1. 分别创建文本、图片、视频节点。
2. 文本节点连接文本节点。
3. 图片节点连接文本节点和视频节点。
4. 已生成的视频节点继续连接另一张图片或文本节点。
5. 尝试创建重复连线和循环连线。

**预期结果**：

- 文本与文本可以连线。
- 支持的节点类型可反复作为上游或下游继续连线。
- 已生成的视频不是终点，可以继续参与后续分镜或生成流程。
- 重复连线、非法类型和循环连接被阻止，并给出明确提示。
- 合法连线不会因为一次非法操作被删除。

### CANVAS-003 节点编辑和持久化

**步骤**：

1. 重命名节点。
2. 复制并粘贴节点。
3. 创建节点副本。
4. 删除节点后执行撤销，再执行重做。
5. 刷新页面。

**预期结果**：

- 重命名不会错误进入其他输入框。
- 复制节点保留允许复制的内容，但具有独立节点 ID。
- 撤销和重做结果正确。
- 刷新后服务端保存结果与刷新前一致。

### CANVAS-004 画布分享页

**步骤**：

1. 创建包含图片、视频、文本和连线的画布。
2. 打开分享入口。
3. 在分享页面检查节点和连线。

**预期结果**：

- 图片和视频可访问。
- 历史连线正常显示。
- 分享弹窗无多余“完成”按钮，用户可通过关闭按钮退出。
- 分享页不得暴露编辑权限。

## 5.3 图片生成参数与多结果

### IMAGE-001 生成数量按钮

**步骤**：打开图片生成节点的生成参数。

**预期结果**：

- 生成数量仅显示“1张”“2张”“4张”三个按钮。
- 不显示生成数量滑块，不允许选择3张或其他数量。
- 默认选择1张。
- 历史草稿中数量为3或非法值时回退为1张。
- 请求参数分别为数字 `1`、`2`、`4`，不是字符串标签。

### IMAGE-002 图片尺寸、水印与比例

**步骤**：切换图片尺寸、水印和各画面比例。

**预期结果**：

- 选择状态清晰且摘要与当前值一致。
- 参数切换不改变素材预览容器尺寸。
- 图片使用等比例适配，不发生横向或纵向拉伸。

### IMAGE-003 多结果展示

**前置条件**：允许真实生成并使用账号 D。

**步骤**：分别生成1、2、4张图片。

**预期结果**：

- 返回结果数量与选择一致。
- 每张结果可独立预览、下载和继续连线。
- 多结果不会覆盖同一节点中的其他有效结果。
- 刷新后结果仍可访问。

## 5.4 素材选择与 `@` 引用

### MENTION-001 打开素材选择器

**步骤**：

1. 点击底部 `@` 按钮。
2. 关闭后，在输入框中手动输入 `@`。
3. 将光标移动到文本中间，再输入 `@`。

**预期结果**：

- 两种方式均能打开素材选择器。
- 底部 `@` 按钮始终保留。
- 手动输入时，浮层在当前 `@` 所在位置上方展开。
- 选择素材后引用插入当前光标位置。

### MENTION-002 横向素材列表

**步骤**：使用包含9张图片的项目打开素材选择器。

**预期结果**：

- 素材横向排列，不显示成狭窄的竖向列表。
- 图片超过可视区域时可以横向滚动。
- 超出屏幕后不强制整体居中，起始项仍可访问。
- 图片名称、缩略图和引用序号对应正确。

## 5.5 模型与参数选择

### MODEL-001 首次选择与默认恢复

**步骤**：

1. 使用从未保存过模型偏好的项目进入创作页。
2. 检查模型选择器。
3. 选择一个视频模型和一组比例、时长、分辨率。
4. 刷新并重新进入同一项目。

**预期结果**：

- 首次显示“请选择视频模型”。
- 选择模型后模型面板自动关闭。
- 随后自动展开比例、时长和分辨率选择框。
- 再次进入项目时恢复上次模型和参数。
- 不同项目的偏好不得互相覆盖。

### MODEL-002 悬停交互

**预期结果**：

- 鼠标进入模型选择区域后直接显示模型列表。
- 离开整个触发器和浮层区域后关闭。
- 展开瞬间不闪现“生成模型”或空白占位文案。
- 模型卡片不被容器裁切，必要时在浮层内部滚动。
- 已选模型具有明确选中状态。

### MODEL-003 脚本模型

**预期结果**：

- 爆款脚本默认选择“不使用脚本”。
- 选择其他脚本能力时正确显示名称。
- 只有一个脚本模型时不要求用户额外选择，前端直接使用默认模型。
- 系统自动选择模型不应被判定为用户编辑，不应误弹“丢弃草稿”。
- 用户手动改变模型后切换模式，应按需求提示确认。

## 5.6 生成前素材校验

### MATERIAL-001 当前团队有效素材

**预期结果**：当前团队中已经入库且有效的素材允许进入积分确认和提交阶段。

### MATERIAL-002 跨团队素材

**步骤**：把工作空间二的素材带入工作空间一的生成节点。

**预期结果**：

- 连线或提交前阻止使用。
- 提示素材不属于当前团队。
- 不创建任务，不扣积分。

### MATERIAL-003 失效和查询失败

**预期结果**：

- 已删除或不可用素材提示具体素材 ID 或可定位信息。
- 素材核验接口失败时提示“暂时无法核验”。
- 查询失败不得误报为“跨团队素材”。
- 校验失败不创建生成任务。

### MATERIAL-004 生成结果有效性

**预期结果**：

- 结果写回节点前，应在当前团队有效素材列表中找到对应素材 ID。
- 素材列表分页时仍能找到后续页中的结果。
- 仅能拼出下载 URL 但素材不存在时，不得标记为成功结果。

## 5.7 视频任务类型与时长

### VIDEO-001 编辑意图拦截

**步骤**：连接源视频，输入“替换人物”“删除字幕”“把背景改成室内”等编辑指令，但选择普通视频生成。

**预期结果**：

- 提交前拦截。
- 提示切换为视频编辑。
- 不创建任务，不扣积分。

### VIDEO-002 Seedance 2.5 时长边界

**预期结果**：

- 模型未声明上限时按30秒上限校验。
- 30秒允许继续。
- 30.2秒显示为约31秒并拦截，不能四舍五入为30秒后放行。
- 提交前再次读取真实时长，避免界面值与实际文件不一致。

### VIDEO-003 其他模型未声明上限

**预期结果**：未声明时长上限的其他模型不得被前端统一套用15秒限制，应以模型约束或后端结果为准。

### VIDEO-004 错误中文化

**预期结果**：参考视频过长、参考视频总时长超限、版权限制等已知英文错误转换为可操作的中文提示，并保留重试或更换素材的入口。

## 5.8 视频预览、播放与下载

### PREVIEW-001 可拖动播放

**步骤**：打开视频预览，播放并拖动进度条。

**预期结果**：

- 视频可以播放。
- 进度条显示当前时间和总时长。
- 点击或拖动进度条后，视频跳转到相应时间。
- 竖屏、横屏视频都保持原始比例，不拉伸变形。

### PREVIEW-002 放大和关闭

**预期结果**：

- 点击视频区域打开放大预览。
- 点击视频、控制条或内部按钮不会关闭。
- 点击遮罩空白区域关闭。
- 关闭后后台播放停止。

### PREVIEW-003 下载

**预期结果**：

- 下载使用有效资源地址。
- 过期签名 URL 不作为长期持久化数据。
- 下载失败显示错误，不得生成空文件。

## 5.9 AI 文案辅助

### POLISH-001 连续改写与复原

**步骤**：

1. 输入原始文案 A。
2. 点击“我帮你写”，得到 B。
3. 再次执行，得到 C。
4. 连续点击“复原”。

**预期结果**：

- 页面不再显示“AI一键润色”，统一显示“我帮你写”。
- 第一次复原从 C 返回 B，第二次从 B 返回 A。
- 请求失败时保留当前文案，不清空输入框。
- 画布提示词、分镜、台词、字幕、音效和视频修改意见使用一致行为。

自动化不校验 B、C 的具体语义，只校验内容发生替换、历史顺序和失败恢复。

## 5.10 失败详情与任务中心

### TASK-001 失败详情

**预期结果**：

- 失败任务显示明确状态和可理解原因。
- 失败详情可以展开和关闭。
- 版权、时长、素材不可用等错误不会只显示原始英文堆栈。
- 失败任务不会显示成成功，也不会产生可下载的空结果。

### TASK-002 任务恢复和筛选

**预期结果**：

- 任务中心区分进行中、成功和失败。
- 可按团队成员筛选。
- 缩略图预览正常。
- 刷新页面后进行中的任务可以恢复轮询。
- 迟到的旧任务响应不得覆盖较新的生成结果。

## 5.11 素材管理到创作页跳转

### RESOURCE-001 图片素材跳转

**步骤**：从素材管理把图片添加到智能成片、爆款复制和无限画布。

**预期结果**：

- 三个入口均携带同一个有效素材 ID、稳定地址和来源类型。
- 无限画布按图片节点接收素材。
- 返回素材页后原筛选状态尽可能保留。

### RESOURCE-002 视频素材跳转

**预期结果**：视频使用耐久素材流地址，不使用即将过期的预览地址；目标页面可以播放和继续创作。

## 5.12 团队入口与数据统计

### TEAM-001 角色入口

| 角色 | 应显示 | 不应显示 |
| --- | --- | --- |
| 所有者 | 邀请成员、团队数据、当前团队重命名 | 无权限提示 |
| 管理员 | 成员管理、团队数据 | 当前团队重命名 |
| 普通成员 | 团队成员、团队数据 | 邀请成员、成员管理、重命名 |

补充预期：切换团队后个人面板不自动关闭；双击团队名或点击“团队数据”均可进入数据看板。

### STATS-001 默认 Tab

**预期结果**：

- 普通成员默认进入“个人”。
- 管理员和所有者默认进入“团队”，并可切换到个人。
- 团队 Tab 原有布局和数据含义不变化。

### STATS-002 个人数据

**预期结果**：

- 可按月份筛选。
- 展示本人项目数、生成视频数、消耗积分、平均每个视频消耗积分。
- 展示本人在当前团队内产生的消耗。
- 普通成员可以看到自己的消耗，但不能看到其他成员隐私明细。
- 个人页不显示成员人数和贡献排行。

### STATS-003 每日消耗积分

## 7. 自动化实现建议

### 7.1 浏览器层

- 使用 Playwright Chromium 作为主执行浏览器。
- 核心画布、弹窗和视频预览增加移动端 Chromium 冒烟，但画布完整编辑以桌面端为主。
- 元素优先通过 `role`、可访问名称、稳定 `data-testid` 定位，避免依赖易变化的 CSS 层级。
- 画布节点和连线应结合 DOM、React Flow 数据或保存接口验证，不能只依赖截图。

### 7.2 接口层

重点观测：

- 任务提交请求是否包含正确的模型、比例、分辨率、时长、数量和素材 ID。
- 校验失败时任务提交接口调用次数为0。
- 生成任务轮询状态是否由进行中最终转为成功或失败。
- 积分预估请求和正式提交参数是否一致。
- 项目或画布保存接口是否成功，刷新后数据能否恢复。

### 7.3 视觉层

建议截图断言：

- 模型选择浮层没有被裁切。
- `@` 素材选择器横向展示。
- 图片和视频没有拉伸。
- 通知角标、个人数据页和每日消耗积分模块。

截图比较应允许轻微抗锯齿差异，不对AI生成内容本身做视觉基线。

## 9. 缺陷判定与测试报告

每个失败用例至少记录：

| 字段 | 说明 |
| --- | --- |
| 用例编号 | 如 `CANVAS-002` |
| 环境 | URL、浏览器、视口、提交版本 |
| 测试账号角色 | 普通成员/管理员/所有者 |
| 前置数据 | 项目、画布、素材 ID |
| 实际步骤 | 自动化实际执行的操作 |
| 预期结果 | 本 PRD 对应要求 |
| 实际结果 | 页面表现和错误信息 |
| 证据 | 截图、视频、控制台、网络请求 |
| 是否扣费 | 预估积分、实际扣费 |
| 可复现性 | 必现/偶现/仅特定数据 |

以下情况直接判定为 P0 缺陷：

- 校验失败后仍创建任务或扣除积分。
- 跨团队素材可以被提交生成。
- 画布刷新后节点或连线丢失。
- 生成成功但结果素材无法再次使用。
- 普通成员看到其他成员的个人消耗明细。
- 音频入口重新出现在用户界面。
- 模型、比例、时长、数量的页面选择与实际请求不一致。
