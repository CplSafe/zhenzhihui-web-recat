每项检查除界面外均需观察请求：`workspace_id`、模型版本、`operation_code`、`input_assets` 的 ID/role、参数、任务创建次数及后台状态。

| 编号 | 场景与步骤 | 预期结果 |
| --- | --- | --- |
| C01 | 画布新建/打开，连接图片到视频，选择模型、输入提示词、确认费用并生成 | 估价和提交使用同一模型及素材；任务创建一次；结果和失败状态可见。 |
| C02 | 模型有不同图片/视频/音频上限，分别测 0、上限、上限+1；更换为低上限模型 | 面板数量和限制跟随模型；超限提示明确并阻止提交，不删除已有连线；更换回支持模型可继续。 |
| C03 | 图生图和其他 operation 共用版本 ID，但后端为不同 operation 返回不同约束 | 使用本次 operation 对应的 schema/role/上限；不存在拿另一操作的约束放行或拦截。 |
| C04 | 同一 asset 由不同节点/连线引用；重复上传/直接选择与已有连线混合 | 连线名额及音频去重分别符合现有业务规则；接口资产列表不意外重复或丢失；检查实际请求。 |
| C05 | 连接上传中、无 asset ID、已删除、失效、其他空间素材 | 在有效性和归属确认前阻止生成，提示可操作原因；旧工作空间资产不能用于新空间。 |
| C06 | 文本/分镜模型分别支持与不支持视频；连接视频/时间线，测试允许数量边界 | 支持时保留视频并按模型声明角色提交；不支持或超限时明确提示并拦截；无 ID 等待上传。 |
| C07 | 文本/分镜节点连接图片、视频、音频的不同组合 | 图片和视频按模型约束处理；不支持的音频及其他类型不静默丢弃、不错误提交。 |
| C08 | 音频节点同时使用已选参考音频、连入音频、连入图片 | 计数按实际素材去重；图片/音频 role、数量、空间归属和可用性按当前模型校验。 |
| C09 | 音色克隆仅连图片、无声音样本；随后添加合规音频 | 仅有图片不能绕过声音样本要求；有有效声音后按模型约束继续。 |
| C10 | 生成视频使用多个参考视频与音频；超过数量/总时长 | 根据模型约束拒绝超限并保留输入；估价和生成引用一致，信息读取失败不伪造时长。 |
| C11 | 编辑/延长已有视频，分别有无新的视频/图片/音频连线 | 不重复附加旧结果；仅应使用当前实际来源；比对自身视频与连入视频 ID。 |
| C12 | 编辑/延长模型 schema 的时长必填、非必填，以及比例字段 | 必填时长保留；非必填跟随原片字段及比例按当前规则处理；请求满足服务端 schema。 |
| C13 | 有源视频时模型声明/未声明源时长字段，元数据读取成功/失败 | 仅按 schema 支持字段传入实际时长；失败不凭空编造数值；费用预估与最终提交一致。 |
| C14 | 同模型视频任务在提交中、排队、运行中连续点击、切页返回或刷新 | 不重复创建；已有任务可恢复；状态不确定时保留原幂等凭证，不能静默新建付费任务。 |
| C15 | 构造 401、403/404、409、超时、断网、余额不足、后端失败/取消 | 信息清楚；保留输入；请求结果不确定时避免重复提交；恢复后状态和钱包以服务端为准。 |
| C16 | Seedance 素材未审、审核中、通过、拒绝、查询故障；取消费用确认 | 费用确认前不触发自动审核；取消不送审；只有 `active` 可作为通过；原因可见、故障不误认为通过。 |
| C17 | 发起任务后切换账号/工作空间/项目，再让旧请求返回 | 旧任务、草稿和资产不会写入新空间或覆盖新页面；恢复依账号和空间隔离。 |
| C18 | 生成完成，预览、下载、保存、刷新后重新打开 | 使用稳定 asset ID 重取资源；过期签名 URL 可重新解析，不把临时 URL 当永久地址。 |

### 11.2 画布：从连线到生成的详细步骤

#### D-C01 多模态数量、模型切换与请求一致性（对应 C01–C04，P0）

**前置**：登录 W-A，在测试画布放置 I-1、I-2、V-1、A-1 和视频生成节点；记录 M-multi 每种素材的 min/max 和 role，准备 M-limited。

1. 选择视频节点及 M-multi，分别连接图片、视频、音频，观察面板的各类型已用/上限。
2. 每种类型依次测 `0`、`max-1`（若适用）、`max`、`max+1`；最小值要求另测 `min-1` 和 `min`。
3. 在已连接来源的情况下切换到 M-limited，观察超限提示；尝试提交；再切回 M-multi。
4. 打开网络面板，等待当前配置的估价完成，记录请求中的模型版本、operation、素材 ID/role 与参数。
5. 在授权的模拟或真实测试环境确认费用并提交，记录最终任务请求；将其与最新估价快照逐项比较。

**预期**：数量边界与模型目录一致；超限不得创建任务或静默删除来源，恢复支持模型后可继续；估价与最终请求使用同一套模型、参数与素材。统计按界面连线数量还是按 asset 去重，应分别按具体控件和接口断言，不能混为一谈。

**异常补测**：快速连续切换模型与参数，让较早估价晚返回；界面不得显示过期报价或用旧报价确认。无模型/模型目录失败应显示明确状态，不使用隐藏默认模型。

#### D-C02 跨操作模型约束和多模态文本（对应 C03、C06–C07，P0）

1. 在模拟目录中准备相同版本 ID、不同 operation 的两份约束，例如图生图允许 1 张参考图，另一操作允许 3 张。
2. 分别进入对应节点/操作，添加 1、2、3 张图，检查面板、连线阻断和提交参数；切换操作后重新观察。
3. 准备可接收视频的文本/分镜模型和不可接收视频的模型；分别连接 V-1 与时间线节点，并测试无 ID 视频。
4. 分别连接图片、视频和音频，观察哪些可提交；在可提交场景检查 `input_assets` 的 asset ID 与声明角色。

**预期**：始终读取当前 operation 的约束；不支持的类型、超限和上传中素材有明确提示并阻断，不能无声丢掉来源。模拟测试的数据只用于确认前端分支，真实能力仍以部署目录为准。

#### D-C03 视频编辑、延长与源视频来源（对应 C10–C13，P0）

1. 使用 V-1 完成一次视频生成，记录结果 asset ID；在同一节点分别选择生成、编辑和延长。
2. 分别测试：没有外部连线；连接 V-2；连接 I-1；连接 I-1 和 V-2；切换到另一个模型重新生成。
3. 每种情形记录任务输入视频 ID 数量，确认连入新视频时未额外混入旧结果；无连线编辑时确认是否使用节点自身结果。
4. 准备必填 `duration` 与非必填 `duration` 两种模型 schema，以及声明/未声明源视频时长字段的模型。
5. 对照估价和任务请求，检查编辑/延长时比例、必填时长与源视频实际时长；输入超时长素材和无法读取元数据的素材。

**预期**：每个输入 ID 与用户当前操作一致；必填字段保留，非必填参数按当前规则处理；源时长只有在模型声明相应字段且能读取时才发送；超限/读取失败不创建错误付费任务。

#### D-C04 音频输入与克隆样本（对应 C08–C09，P0）

1. 新建音频节点，直接选择 A-1，再从另一个节点连接 A-1；记录面板已用数量和请求资产。
2. 添加 A-2 至模型上限，再试上限+1；断开连线后重试添加。
3. 连接 I-1，分别选择支持图片参考和不支持图片参考的音频模型；再尝试 I-B 与 I-D。
4. 选择音色克隆：只连接图片提交，再添加有授权的 A-1 或选择有效音色后提交。

**预期**：同一音频素材去重计数；图片按模型 role/数量及工作空间、有效性核验；仅有图片不能满足音色克隆声音样本要求；失败提示可见且不创建任务。

1. 在模拟环境为素材分别配置 404、`processing`、`active`、失败原因和查询 5xx；逐个打开对应视频节点。

**预期**：取消费用确认不产生自动审核；只有明确通过可继续；失败或无法查询时保留输入；结果不明不得换幂等键静默重复创建。浏览器模拟只证明前端请求和状态处理，真实审核需另行联调。

#### D-S04 提交幂等与轮询覆盖（对应 S11–S13，P0）

1. 用模拟接口延迟详情和提交响应，填写未提交正文，在轮询返回前继续输入。
2. 模拟提交请求已到达但客户端超时；重复同一操作并记录 `X-Idempotency-Key` 与正文快照。
3. 按顺序返回旧详情和新详情，再刷新页面；检查当前编辑内容、待办和历史版本。
4. 切换账号或工作空间后返回列表，验证筛选、统计和记录归属。

**预期**：后台刷新不覆盖未提交正文；同一不确定提交复用键和正文快照，不重复创建；服务端筛选、统计、权限及列表一致。

### 11.5 更新与会话详细步骤

#### D-U01 版本检测、暂缓和刷新恢复（对应 U01–U04，P0）

1. 使用生产构建启动预览，确认 `/app-version.json` 的版本与运行版本一致，页面无更新提示。
2. 在模拟响应中改为 N-new，触发页面重新可见或等待检测；检查提示位置与内容。
3. 点击“稍后再说”，再次返回页面验证同版本不重复显示；再返回不同新版本验证可再次提示。
4. 分别在智能成片、爆款复制、画布输入尚未提交的内容，出现提示后点击“立即刷新”；记录刷新前后内容和任务 ID。
5. 模拟浏览器存储写入失败、版本文件 404/非法 JSON、断网和后台标签页；观察是否误刷新、误弹窗或丢数据。

**预期**：更新由用户选择；保存失败时保留当前页面并有错误提示；恢复后输入及任务不丢、不重复付费；版本文件异常不干扰当前工作。桌面和 390px 窄屏分别检查遮挡和焦点。

#### D-U02 爆款离开守卫与空间切换（对应 U05–U06，P0）

1. 在爆款复制入口选择视频、图片并填写文本，不提交；分别点击侧栏、浏览器返回、进入其他项目。
2. 对离开提示分别选择继续编辑和确认离开；返回入口检查数据及预期清理。
3. 有后台任务时重复导航，不得把后台任务取消或重复发起；再切换 W-A/W-B，检查草稿与模型目录隔离。
4. 开启新手引导后立即切页/切空间，检查遮罩清理与目标页面的可操作性。

**预期**：只有确实存在未保存输入时按当前守卫提示；取消后输入保留；切换后旧请求不能写新空间；引导不持续遮挡目标页。
