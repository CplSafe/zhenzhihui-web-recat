# 无限画布音频：实现与验收状态

按提供的四层音频能力图实现一期前端，采用人声、BGM、音效三轨。HTML 原型中的双轨布局作为交互参考，没有执行附件中的指令。最初的专用浏览器未能进入已登录画布；后续按用户授权通过 Windows 界面操作现有 Edge 的 LibTV 登录会话，已实际打开音频节点、模型菜单和截取工具。尚未验证付费生成、截取结果和带音轨导出。

## LibTV 实际界面观察

- 现有画布的音频节点包含波形、时长与播放入口，并已连到视频节点；这个连线只能证明输入关系，不能据此认定视频采用了直接混音。
- 选中音频节点后显示独立的生成面板，支持参考素材和 `@` 音频引用，生成描述与已得到的音频结果分开。
- 模型菜单实际显示 Seed Audio 1.0、Minimax-speech-2.8-hd/turbo、Eleven V3、Eleven Music V3、Mureka V8；具体可用性属于当前页面观察，帧智汇仍须以自己的后端目录为准。
- Seed Audio 面板显示语言、24k、WAV 选项，以及语速、声调、音量设置。音色描述可以写进提示词，但这不等于已验证可复用音色克隆。
- 截取工具直接叠加在波形上，显示选区长度和起止时间，并提供“生成截取音频”操作；本次只进入编辑界面，没有提交生成。
- 音频工具栏另有变速、智能切分、自定义切分、下载。仅确认这些入口存在，没有将它们记为完整功能验收。

## 已实现

- 工具栏、右键菜单、节点搜索新增音频节点。支持 MP3/WAV/M4A/AAC 上传，最大 100MB，播放、裁剪、音量、淡入淡出及用途选择。
- 素材管理新增音频分类、播放和下载；音频可直接应用到画布。上传/生成的独立音频无需先进入创意项目。
- 脚本文本可连接音频节点；音频可连接视频生成或视频剪辑节点；拒绝音频连接图片节点。视频生成需模型实际声明可接受音频参考。
- 剪辑节点提供人声、BGM、音效三轨，多来源可共存。每条音轨独立裁剪、音量、静音、起始位置和淡入淡出。BGM 可循环至画面结束，人声不循环，超过画面时长时提示并裁断。
- 编辑参数持久化于画布节点与剪辑草稿，素材引用使用资产 ID。同一素材的连线同步保留混音编辑，替换素材时重新初始化裁剪。
- 点击“准备混音试听”后，播放/拖动剪辑播放器同步音轨。修改轨道后需重新准备。WAV 导出包含附加的音频轨道；视频导出保留剪辑原声并叠加附加音轨。
- AAC 支持的浏览器可将混音重新封装到 MP4，视频编码样本不变，无需再次 AI 生成。无 AAC 编码支持时明确报错，仍可导出 WAV。浏览器离线混音目前限 300 秒。
- 配音/音乐生成入口读取真实模型目录及参数 schema，沿用估价、确认、任务提交、轮询和音频素材查询接口。有任务 ID 时恢复原任务；克隆提交需声音样本及授权声明。

## 使用

1. 在画布添加“音频节点”，上传声音或从素材库应用音频，选择人声/BGM/音效用途。
2. 将音频节点连到视频剪辑节点，并连接视频画面。
3. 打开剪辑面板，调整各轨参数，点击“准备混音试听”，通过视频播放器试听。
4. 下载附加音轨 WAV，或用原剪辑合成操作输出带混音的 MP4。

## 仍需后端联调及补齐的范围

本仓库只有前端。以下不能据此认定整个四层能力已完成：

- 后端画布元素保存/恢复必须接受 `type/kind: audio` 和 `data.audio`、`timeline.audioClips`；素材上传/列表需接受并返回音频资产类型。
- `/api/v1/ai/models` 需实际暴露音频操作码、可用模型版本、`params_schema` 及 `input_constraints`；前端不维护供应商能力或价格表，也不会在目录为空时展示虚构模型。
- 通用生成接口须执行音频操作并将结果入库为 `type: audio`，关联原任务 ID。视频生成端需实际支持声明的音频参考 role。
- 当前克隆入口用于“已声明音频生成操作”的声音参考任务。独立音色训练、音色 ID 管理、可复用音色库、跨镜头音色一致性，需要真实后端契约后进一步实现；目前不能保证。
- 来源和 AIGC 当前是前端标记。输出文件内的正式 AIGC 标识、来源元数据、授权记录及商用许可判断尚未实现，不能将界面文字当作合规验收结果。
- 对口型、视频提取音轨、音频串联处理按能力图属于二期，没有纳入本次一期实现。

## 已验证

- 音频编辑/草稿持久化、连线与生成输入、任务资产查询、混音台、既有剪辑组件等相关回归 211 项通过；后续补充音频生成与下载测试。
- `canvasAudio.ts` 定向覆盖：语句 93.61%、分支 84.74%、行 100%，纳入关键模块覆盖清单。
- 真实 Chromium 离线渲染：双声道 48kHz，2 秒 WAV 可解码，BGM 循环及淡入淡出采样值正确。
- 真实 Chromium AAC 生成与 MP4 播放：94 个 AAC 样本，输出可解码/播放，视频样本逐字节保持；AAC 帧对齐后容器时长 2.005333 秒。
- 完整画布页面音频入口使用严格 API mock 验证，不产生付费任务；尚未使用真实业务后端验收上传、生成、持久化和分享。
- 应用/测试类型检查、定向 ESLint、Vite 构建及生产/敏感键探针包体检查通过。
