# 无限画布音频操作完整流程

本文按当前前端源码梳理画布音频从素材准备、生成与编辑，到时间线试听和导出成片的完整操作链路。后端模型、资产服务和浏览器编解码能力会影响实际结果；文中会区分前端已实现能力和外部依赖，不把尚未验收的能力写成保证项。

## 1. 总体流程

```text
添加音频节点
  ├─ 上传音频 / 从素材库应用
  ├─ 描述并生成配音、音乐或其他音频
  └─ 可选：从视频截取声音参考，或从本机样本库引用
        ↓
音频节点试听、裁剪、调音量、淡入淡出、选用途
  ├─ 下载源音频
  ├─ 导出裁剪后的 WAV
  └─ 保存裁剪后的 WAV 为新素材
        ↓
使用音频
  ├─ 连到音频生成节点：作为参考输入，受模型约束
  ├─ 连到视频生成节点：作为模型参考，是否采用由模型能力决定
  └─ 连到视频剪辑时间线：作为后期音轨，参与试听和最终混音
        ↓
时间线自动准备混音试听 → 人声/BGM 等音轨调整 → 下载混音 WAV
        ↓
校验并合成 MP4 → 上传成片 → 在画布新增独立视频节点
```

重要区别：连到视频生成节点的声音是模型输入参考，不代表一定会在生成视频中听到；连到时间线节点的音频才是前端可明确控制、试听并混入 MP4 的后期音轨。

## 2. 功能清单与当前状态

| 功能 | 当前前端能力 | 主要依赖或边界 |
| --- | --- | --- |
| 音频节点 | 添加、上传、播放、编辑、下载、连接其他节点 | 画布后端需保存 `audio` 节点数据，素材服务需支持音频资产 |
| AI 配音/音频生成 | 按工作空间模型目录显示操作、参数、费用；提交任务、轮询并展示结果 | 依赖 `/api/v1/ai/models`、费用预估、任务接口和结果入库 |
| 音色克隆 | 操作码包含 `clone` 的模型可要求参考音频和授权声明 | 目录没有独立克隆模型时不能使用；前端勾选不等于服务端审核，也不代表训练出可复用 `voice_id` |
| 参考音频 | 上传、拖放/粘贴、从画布引用、试听和移除 | MIME、数量、角色由当前模型目录约束；素材须属于当前工作空间 |
| 视频提取声音样本 | 浏览器端提取音轨，裁选 5～30 秒并转为 WAV 上传 | 受视频封装、音轨编码、浏览器解码能力限制；不做分离人声或音色训练 |
| 本机声音样本库 | 搜索、试听、重命名、引用、移除收藏、最近引用排序 | 只保存在当前浏览器的 localStorage，不跨端同步、不删除服务端素材 |
| 音频节点编辑 | 裁剪、音量、淡入淡出、人声/BGM/音效用途；导出或保存裁剪 WAV | 编辑值保存在画布节点；音频变速和 AI 人声分离未实现 |
| 时间线混音 | 音频节点接入视频时间线；调整位置、裁剪、音量、静音、循环、淡入淡出和原视频音量 | 人声、BGM 是标准显示轨；历史 `sfx` 数据可兼容显示为“历史音效”，不等于完整开放的三轨产品能力 |
| 同步试听 | 自动准备 WAV 试听，音频就绪后才允许带音轨的视频起播，并跟随播放头 | 浏览器解码/播放失败时需重试；浏览器可能阻止自动播放 |
| 混音 WAV | 导出时间线附加音轨的 WAV | WAV 不包含时间线原视频声音；离线混音时长上限 300 秒 |
| MP4 成片 | 视频片段拼接后，将原声和附加音轨混音、AAC 编码并封装为 MP4 | 依赖浏览器 `WebCodecs AudioEncoder` AAC 支持和可解码的 MP4 素材 |

## 3. 详细操作流程

### 3.1 添加音频节点并准备素材

1. 在画布工具栏、节点添加入口或素材导入流程中添加音频节点。
2. 选择一种素材来源：
   - **上传本地音频**：支持 MP3、WAV、M4A、AAC，单文件最大 100MB。浏览器先读取时长，再调用素材上传接口；上传成功后节点记录素材 ID、工作空间、标题、来源和音频设置。
   - **从素材库应用**：选择已上传的音频素材生成画布音频节点。引用的素材应当属于当前工作空间。
   - **AI 生成**：在音频节点的生成面板填写描述/配音文案并选择当前空间实际开放的音频模型，见 3.2。
3. 上传成功后可以在节点直接播放、暂停、拖动播放进度。若无法解码或播放，检查文件格式/编码后重新上传；上传未成功时不会把新素材写成节点当前结果。

节点音频数据保存在 `data.audio`，主要包括用途 `lane`、时长、裁剪入点/出点、音量、静音、循环、淡入/淡出和来源。节点保存的是资产 ID，不把短期签名播放 URL 当作持久素材标识。

### 3.2 AI 配音、音乐或音频生成

1. 打开音频节点的生成面板。模型列表来自当前工作空间的 `/api/v1/ai/models` 音频目录；前端不根据模型名称伪造模型或静态猜测操作码。
2. 选择可用模型及操作。参数字段、默认值、必填项、枚举、数值范围、音频参考角色及数量限制以目录 schema 和 `input_constraints` 为准。
3. 输入生成描述或配音文案，也可以把文本节点连入音频节点。连入的文本和面板文案合并后提交，合计最多 2000 字。
4. 按需要添加参考音频：本地上传、拖放/粘贴音频、引用画布中的音频节点，或从声音样本库引用。提交前会核对工作空间、资产有效性、模型支持的格式、最大文件大小和参考数量。
5. 若模型操作码是克隆类操作，还必须提供有效参考音频并勾选授权声明。该声明只是用户在前端作出的确认，不是服务端授权审核。
6. 前端以当前 prompt、参数、输入素材和模型版本调用费用预估。费用无法确认、余额不足、字段校验失败或参考素材无效时，不进入任务提交。
7. 费用达到界面设定的高额确认条件时会要求用户确认。确认后生成幂等键并提交任务；任务 ID 和 `processing` 状态写入节点。
8. 节点显示生成进度。页面刷新后会根据已有任务 ID 继续等待同一个任务，不重新创建任务或重复提交。
9. 任务成功后，前端校验任务结果是否已入库为当前空间的音频资产，再读取时长并更新节点。时长暂时读取失败不会把已入库的结果改判为失败，播放器可后续补齐时长。
10. 最近生成结果写入节点历史，最多保留 20 个去重版本；可从生成历史切回先前版本。

失败与恢复：

- 任务提交失败时保留错误信息和失败上下文；检查模型权限、费用、参数和素材后再次生成。
- 已提交任务轮询失败时，节点保留任务 ID 和失败状态；刷新后仍以原任务恢复读取。
- 任务显示完成但结果资产暂未入库时，提示稍后查看；不能把它当成可连接下游的有效音频。
- 模型列表为空时，切换到开放音频能力的工作空间或联系管理员开放目录权限。当前真实模型和空间权限需要登录后重新查询，旧的空间目录结果不应视为实时状态。

### 3.3 从视频提取声音参考并管理样本

1. 在生成面板打开“声音样本库 / 视频提取”。
2. 上传包含音轨的视频：前端支持普通 MP4、MOV、M4V，文件不超过 100MB、视频不超过 5 分钟。WebM、分片 MP4 或浏览器不能解码的编码不在支持范围内。
3. 浏览器解复用视频音轨并使用 `OfflineAudioContext` 解码。没有音轨或解码失败时会提示转换视频，或直接上传音频文件。
4. 选择 5～30 秒片段，填写样本名称并试听；推荐清晰的单人声音，避免背景音乐和多人重叠。
5. 勾选“本人或已获授权”的确认后，前端把选区转为单声道 PCM16 WAV，并按模型当前允许的音频约束上传。
6. 上传成功后可把样本引用到当前生成节点。失败会保留选区和授权状态，检查网络、格式或模型约束后重试。
7. 对已上传的参考音频可收藏到本机声音样本库；之后可搜索、试听、重命名、引用或移除收藏。

边界：

- 该功能只是提取声音参考，不会分离人声、去除背景音乐、训练音色或生成 `voice_id`。
- 收藏记录按账号和工作空间隔离，最多保存 100 条，数据在当前浏览器本地；清除浏览器站点数据会丢失收藏，但不会删除服务端素材。
- 引用收藏时会重新确认资产仍存在且属于当前工作空间；失效资产需移除收藏并重新上传。
- 当前真实工作空间是否存在可用于克隆的模型，必须以模型目录和后端授权为准。

### 3.4 编辑音频节点

选中音频节点后可完成以下操作：

1. **试听/定位**：播放、暂停或拖动进度；键盘 `I` / `O` 可把当前播放位置设为裁剪入点/出点，上下方向键按 0.1 秒步进，按住 Shift 按 0.01 秒步进。
2. **裁剪**：设置裁剪起点和终点，或重置为完整音频。
3. **音量**：调整音频节点自身的音量；可同时试听修改。
4. **淡入/淡出**：设置淡入和淡出秒数，导出及时间线混音会应用音量包络。
5. **用途**：选择人声/配音、BGM 或音效。BGM 默认循环；最终时间线以其轨道设置决定是否循环。
6. **下载源音频**：下载未按当前裁剪和音量重新渲染的源素材。
7. **导出裁剪与音量 WAV**：把当前选区、音量和淡入淡出渲染为 WAV 并下载，不覆盖源素材。
8. **保存为新素材并用于下游**：将编辑效果渲染为新的 WAV 资产，并把当前节点切换到新素材；后续连线使用新素材。需要保留原素材时，先复制节点或保留原资产。

节点播放器无法播放时提示重新上传或稍后重试；导出/保存遇到解码、网络或资产入库错误时显示错误提示，源素材不会因导出失败被替换。当前没有音频变速、人声分离或音色锁定功能。

### 3.5 将音频用于生成或视频

**音频生成参考**

- 把文本节点连到音频生成节点可传入文案；把音频节点连入生成节点或通过 `@` 引用可传入音频参考。
- 只有模型目录声明支持参考音频时才能提交；实际 `role`、数量和 MIME 由模型约束决定。
- 参考素材必须已经上传/生成完成并属于当前工作空间。

**视频生成参考**

- 把音频节点连到视频生成节点时，音频仍作为模型参考输入；提交时同时固定素材 ID 和裁剪、音量设置。
- 对新提交的视频任务，生成完成后会关闭模型原声、合入固定的原音频并上传新 MP4。预览、下载与下游引用使用合成后的素材。默认从零开始的多段人声按输入顺序串接，背景音乐和音效沿用各自设置；不保证口型同步。
- 配音长于视频、格式或浏览器编码能力不支持时，保留视频任务并显示失败原因；“重试配音合成”只重试合成，不重新提交付费生成。也可以使用下一节的时间线后期混音路径调整时长。旧任务没有提交时的配音快照，不会自动替换其声音。

### 3.6 时间线绑定、混音与同步试听

1. 添加/打开视频剪辑时间线节点，把可用视频节点连接到时间线，或在剪辑面板中添加视频片段。连线的视频片段按时间线顺序成为画面素材。
2. 把已就绪的音频节点连到时间线，或在混音台“添加音频”中选择当前工作空间内尚未加入的音频节点。音频连线会同步到 `timeline.audioClips`，并以来源节点 ID 关联；同一来源保留已经调整过的时间线设置。
3. 调整音轨：
   - 轨道用途：人声或 BGM；旧有 `sfx` 数据可显示为“历史音效”。
   - 起始位置、裁剪起点/终点、淡入/淡出、音量、静音。
   - BGM 可以循环铺满剩余画面；非循环音频超出剩余画面会在画面结束处截断，不会自动改写上游音频。
   - 同轨重叠会同时混音，界面会提醒，不会覆盖源素材。
   - 可以独听某条标准轨；独听是试听辅助，不作为导出时删除其他音轨的设置。
4. 设置原视频声音音量或静音。它和外加音轨分开管理，最终 MP4 混音时会按该值纳入。
5. 第一次加入音频或修改轨道后，混音台自动在浏览器本地渲染 WAV 试听；改动停止短暂时间后重新准备。准备失败可点“重试音频试听”。
6. 有附加音轨时，视频播放会等试听音频加载就绪，再开始音画同步播放。拖动视频播放头时音频也定位到相同时间；浏览器阻止播放时按提示重新点击播放或重试。
7. **导出混音 WAV** 会导出附加音轨混音，不包含时间线原视频声音；需要含原声的最终成片请走 MP4 合成。

离线混音为 48kHz 双声道处理，输出 PCM16 WAV；单次渲染最长 300 秒。音频单条素材最大 100MB，混音时顺序下载和解码，并在当前剪辑会话缓存部分已解码音频。

### 3.7 合成最终 MP4

1. 确认时间线上有可用视频片段，并完成音轨、原声和时长设置。
2. 点击“合成为一条视频”。前端重新读取视频真实时长并校准裁剪点，然后校验素材、片段数、最小时长和总时长。
3. 视频在浏览器本地拼接；规格一致时走无损拼接，规格不一致时按需重编码并显示进度。源视频总下载量超过 512MB 时会阻止本地合成。
4. 存在附加音轨或原声音量变化时，前端下载音频素材、离线混音并编码 AAC，随后将新音轨封装到 MP4。音视频处理失败会提示明确错误，不创建成片节点。
5. 合成文件通过素材上传接口保存。成功后在画布新建一个独立视频节点并连接时间线；时间线节点保留为编辑源，可继续修改并生成新版本，不覆盖之前的成片。
6. 合成结果提示若包含关键帧吸附等信息会以提示消息展示；出现错误时可调整素材/参数后重新合成。

合成限制：

- 最多 20 个视频片段；时间线总时长最多 300 秒；每段至少 0.2 秒。
- 单个视频片段且没有附加音轨、原声也未改变时，不允许单独合成；至少加入第二个视频片段，或添加音频/调整原声后再合成。
- 合成依赖浏览器支持 MP4/AAC 处理。若浏览器不支持 AAC，可单独下载附加音轨 WAV，但不能完成带音轨 MP4 输出；建议使用支持 WebCodecs AAC 的 Chromium 浏览器。
- 时间线视频合成是本地处理，不调用 AI 视频生成模型，也不会改变源视频画面质量（规格不一致时可能重编码）。

## 4. 保存与恢复规则

- 音频节点的素材引用、裁剪/音量/淡入淡出设置、参考音频列表、生成任务信息及结果历史属于画布节点数据；时间线音轨和原视频音量属于时间线草稿数据。
- 云端能否跨刷新/设备恢复这些信息，要求画布保存与恢复接口完整接受音频节点和时间线音频字段。前端保存状态变更不等于后端部署已验证。
- 稳定素材以 `assetId` 和工作空间 ID 识别，播放地址在读取时重新生成；不要把临时 URL 当作长期资产。
- 在途生成任务通过任务 ID 恢复轮询；成功结果需在资产服务可查后才可使用。
- 时间线音频使用来源节点 ID 关联。断开音频连线会从同步来源中移除关联音轨；需要继续使用时重新连接并检查剪辑参数。
- 每次合成产出新的独立视频节点，源时间线保持可编辑，方便后续修订和再次导出。

## 5. 后端与浏览器依赖清单

要让端到端流程真实闭环，部署环境需满足：

1. `/api/v1/ai/models` 返回当前工作空间实际可用的音频模型、操作码、版本、参数 schema 和 `input_constraints`。
2. 费用估算、通用 AI task 提交/查询支持所选音频操作；完成任务后返回可查询的音频资产 ID 和正确的音频类型。
3. 资产上传、列表、鉴权、下载接口允许音频 MIME 和由视频截取生成的 WAV。
4. 画布服务保存/恢复 `kind: audio`、`data.audio`、`audioReferences`、任务状态/结果历史，以及 `timeline.audioClips` 和原声设置。
5. 视频生成后端只在模型契约允许时接收音频参考，并明确参考的语义；不能仅凭前端连线推断模型会采用。
6. 如果产品需要真正的音色克隆、跨设备音色库、角色音色锁定或服务端授权审查，后端需提供独立、明确的 API 与数据模型；现有本机收藏和普通音频资产不足以实现这些能力。
7. 用户浏览器需支持源素材解码、`OfflineAudioContext`、文件下载；合成带音轨 MP4 还需支持 WebCodecs AAC。

## 6. 目前未闭环或不能承诺的能力

- **独立音色训练及可复用音色 ID**：当前视频截取只产出 WAV 声音参考；是否能模仿音色取决于所选模型和后端能力。
- **跨设备音色库**：现有库是本机收藏，不是服务端音色目录。
- **服务端授权审核**：界面授权勾选只是用户声明。
- **保证视频模型采用参考音频**：需视频模型真实支持，且由服务端执行其输入语义。
- **全功能三轨音频工作站**：当前时间线稳定呈现/编辑主路径是人声与 BGM；SFX 有兼容数据处理，不代表完整三轨交互已验收。
- **变速、人声分离、对口型、跨镜头角色音色锁定**：当前代码未提供完整可用链路。
- **真实业务端到端质量验收**：单元测试、mock、浏览器合成 WAV/AAC 测试不能代替真实账号下的模型生成、克隆质量、上传入库、刷新恢复和最终 MP4 听感验收。

## 7. 端到端验收清单

建议用已授权的真实工作空间和可控测试素材逐项验收；不要用无授权的人声样本，也不要把测试模型费用当作免费。

- [ ] 音频目录显示当前空间实际可用模型和参数；空目录时提示切换空间/联系管理员。
- [ ] 上传 MP3/WAV/M4A/AAC 后资产入库，刷新画布后仍能播放；超 100MB 或不支持格式被拦截。
- [ ] 配音/音乐生成完成后结果资产可查、可播放；刷新在途任务只恢复原任务；历史版本可切换。
- [ ] 参考音频格式、数量、工作空间和失效资产检查均符合模型目录；失败能修改后重新提交。
- [ ] 视频样本提取支持范围内素材，5 秒与 30 秒边界校验有效；无音轨/不兼容编码有明确提示；上传失败保留选区。
- [ ] 样本收藏、搜索、试听、重命名、引用、移除可用；确认本机存储清理不会删除服务端素材。
- [ ] 音频节点裁剪、音量、淡入淡出试听正确；导出 WAV 与“保存为新素材”均有效，保存后下游使用新资产。
- [ ] 音频连到视频生成节点时确认后端模型是否支持并实际消费该参考；不可只以连线存在判定通过。
- [ ] 音频连到时间线后轨道位置、裁剪、音量、静音、循环和淡入淡出正确；刷新后草稿恢复。
- [ ] 自动试听就绪门控有效；播放/拖动同步正确；试听失败可重试。
- [ ] 混音 WAV 包含外加音轨、不包含原视频音频；MP4 则按设置合入原声与外加音轨。
- [ ] MP4 成片可在目标播放器播放；反复合成会新增成片节点而不覆盖时间线或旧版本。
- [ ] AAC 不支持、素材下载失败、超出大小/时长限制、任务/资产入库失败时均有可理解错误，并能保留可恢复的源数据。
