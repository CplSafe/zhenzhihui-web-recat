# 无限画布全流程交互体验蓝图

> 文档目的：从用户第一次进入无限画布开始，梳理画布列表、编辑器、节点生产、协作分享、保存恢复和异常恢复的完整体验，并重点规定每个交互事件的动态反馈。本文是体验方案，不代表建议已经实现；本次只整理文档，不修改应用代码。
>
> 依据：当前仓库 `CanvasListView`、`CanvasView`、`components/canvas/**`、`utils/canvas*` 和现有快捷键/音频/分享等说明文档。当前工作空间权限、模型目录、费用、素材可用性与后端策略仍以实时接口为准。

## 1. 体验目标与设计原则

无限画布不是一张可无限拖动的白板，而是将想法、素材、生成任务、剪辑和交付结果连成可追溯工作流的创作空间。高级感应来自清晰的操作反馈、稳定的状态、低认知负担和可恢复性，而非单纯增加动效或装饰。

1. **任何时刻都知道当前状态**：画布身份、保存状态、任务状态、当前选择和当前工具都有明确提示。
2. **每个动作有可预期结果**：按钮名称使用动作词；不可用时说明原因；完成后给出结果和下一步。
3. **先保护用户已有内容**：危险操作明确影响范围；异步失败保留输入和素材；刷新、断网、切空间后可恢复。
4. **复杂能力渐进呈现**：默认突出下一步创作动作，模型参数、调音、时间线等按需展开。
5. **画布空间属于内容**：工具、弹窗、提示不遮挡节点；导航不意外改变选区或编辑状态。
6. **操作体系保持一致**：同一动作在按钮、右键菜单、快捷键和工具栏中名称一致，状态同步。
7. **结果可追溯可复用**：节点保留来源、模型/参数、历史版本和任务结果；连接关系表达依赖。
8. **可访问与响应式**：键盘可达、焦点可见、图标按钮有可读名称；窄屏仍能完成主流程。

## 2. 全功能范围地图

### 2.1 画布列表与入口

- 按当前工作空间列出画布，缓存列表后刷新；分页、封面缩略图和空/加载/失败反馈。
- 创建画布并命名；打开画布；重命名本人画布；创建副本；删除画布并二次确认。
- 来自素材入口的素材可带入已有画布，或创建画布后落为节点。
- 工作空间切换时清理旧空间显示，避免短暂展示旧数据。

### 2.2 编辑器工作区

- 画布导航、画布操作菜单、积分、指南、导入文字/分镜、教程、分享。
- 左侧浮动工具：添加节点/素材、拖动模式、锁定节点、搜索、素材库、帮助、历史。
- 节点选择、拖动、框选、平移、连线、连接拖放、分组/解组、对齐整理、复制粘贴、撤销重做、删除。
- 视图控制：缩放、100%倍率、适应画布、网格吸附、连线显示、小地图、界面尺寸、设置、快捷键模式、帮助、节点/连线/失败数量。
- 画布设置：界面尺寸、滚轮行为、空白处添加菜单触发方式、对齐辅助线、连线高亮、快捷键映射、生成通知和提示音。
- 自动保存、云端状态、离线/保存失败提示、恢复草稿和同步冲突处理。

### 2.3 节点与生产能力

| 节点/能力 | 主要工作 |
| --- | --- |
| 文本/脚本 | 输入创意、生成分镜、润色/扩写、结构化分镜、连接下游视频节点 |
| 图片 | 文生图/图生图、模型/比例/数量参数、参考图、蒙版、结果预览/历史/下载/高清处理 |
| 视频 | 文生视频/图生视频/视频编辑、生成方式/时长/比例/声音等参数、参考素材、费用确认、任务进度和结果历史 |
| 音频 | 上传/生成/播放、声音参考、裁剪/音量/淡入淡出、用途、导出与保存新素材 |
| 时间线/剪辑 | 添加视频片段和音轨、编辑顺序/长度/位置/音量/静音/循环/淡入淡出、同步试听、混音导出和 MP4 合成 |
| 上传与素材 | 本地文件、拖放、粘贴、素材库引用、素材预检、来源资产预览 |
| 辅助节点 | 真人素材身份约束、图片工具/裁剪/局部处理、视频详情/预览、高清工作区、全景/帧捕获、语音录制与样本库 |

## 3. 从 0 到 1 的建议用户旅程

### 阶段 A：进入画布

**用户目标**：快速找到已有工作，或清楚地开始新创作。

1. 在工作空间侧栏进入「无限画布」。标题区显示当前空间和画布总数；空间尚未就绪时显示明确的加载状态。
2. 列表优先展示最近编辑画布，卡片展示标题、封面、最后编辑时间、创建者/共享状态及可用操作。封面仍加载时使用统一骨架屏；没有封面时给出内容类型拼贴或中性占位，不显示破图。
3. 首次空状态以「新建画布」为主按钮，提供可选起步方式：空白画布、从脚本开始、导入文字/分镜、从素材开始。避免让新用户先理解节点术语。
4. 创建时输入名称，提示命名用途和字符限制；回车提交、Esc 关闭、重复提交防护。成功后直接进入画布，并把焦点放在最合适的下一步入口。
5. 对带入素材的入口，创建成功后在画布中落下素材节点并定位到该节点；失败时保留素材信息并提供重试，不静默丢弃。

### 阶段 B：第一次进入编辑器

1. 顶栏先呈现返回、画布标题/身份、保存状态；低频操作收进「画布操作」菜单。
2. 新画布显示轻量欢迎面板：一句话说明“节点代表素材或生成步骤，连线代表创作关系”，给出 3–4 个可执行起点和快捷键入口。
3. 同时允许用户直接探索；关闭指南后不再反复打断，后续可从「开始指南」重新打开。
4. 空画布按钮按目标组织：创建脚本、输入想法、添加素材、导入文字/分镜；避免“文本节点/媒体节点”作为唯一解释。
5. 首次创建节点时，在落点旁提供一次性提示：拖连接点到另一节点即可建立流程；提供撤销入口。

### 阶段 C：组织内容与建立关系

1. 添加节点菜单按“创作内容”和“已有素材”分组，并提供搜索/最近使用；隐藏或标记当前空间不可用的能力，不制造可点但无法继续的入口。
2. 新节点落在视口中心或选中节点附近，自动避让已有节点；创建后立即进入可编辑状态，并有轻微但克制的定位反馈。
3. 连接时高亮兼容目标和连线方向；不兼容时说明原因（类型不支持、任务处理中、模型限制或工作空间限制），不能只靠禁止光标表达。
4. 拖拽到节点时预览将建立的连接；释放后显示连接成功。拒绝连接时恢复原位置并给出简短原因。
5. 对多节点操作提供选区计数和就地工具条；单选工具条、框选工具条、节点内部控件不能同时争抢焦点。
6. 分组表达“整理关系”而不隐藏节点；显示分组名称、拖动范围和分组菜单。支持双击改名、拖动整组、解组保留原位置。

### 阶段 D：配置与生成

1. 选择节点后打开对应面板，面板标题明确节点类型和当前任务状态；节点较多时固定面板宽度并允许收起。
2. 提示词区为主操作；模型、比例、时长、数量等参数采用分组控件，显示当前值、可选范围、默认值和模型能力来源。
3. 参考素材以缩略图 + 类型 + 来源标识呈现；添加、移除和插入 `@引用` 均有明确的键盘/鼠标反馈。上传中可取消，失败保留已填写内容。
4. 费用与生成动作在同一决策区：显示估算费用、影响因素和核验状态；费用未核验时不假装可提交。高额确认说明将创建的任务、扣费和素材范围。
5. 主按钮按状态变化：`生成` → `核验素材…` → `提交中…` → `生成中`；避免同一次任务重复创建。可取消的阶段提供取消，已提交的阶段说明不能取消或可否取消。
6. 成功结果直接在节点内预览，提供查看大图/视频、下载、创建副本/继续编辑、查看历史和连接下游。失败显示可理解原因、保留输入和素材，并提供针对性重试。
7. 轮询中断、刷新或恢复后继续跟踪原任务，不重复扣费；任务结果与签名媒体地址分开持久化。

### 阶段 E：剪辑与交付

1. 将视频连接到时间线后，明确“片段顺序由什么决定”；调整顺序时显示拖动抓手和序号，避免通过隐式连线顺序猜测。
2. 添加音轨时展示音频类型、时长、来源和落点；人声、BGM、音效用途与轨道类型对齐。
3. 时间线标出视频/音频片段的起止、裁剪区间、重叠、静音、循环、淡入淡出和原声设置；碰撞和超长情况提供就地提示。
4. 试听状态区分准备中、可播放、浏览器阻止播放、解码失败；播放头拖动和音频保持同步。
5. 导出按钮说明输出内容和计算边界：导出混音 WAV、合成 MP4、下载单个源素材。合成时显示进度阶段（校验、读取、合成、上传），说明本地处理与浏览器能力要求。
6. 成片生成后作为独立视频节点落入画布并连回时间线；保留源片段和时间线，允许继续修改并生成新版本。

### 阶段 F：分享、恢复与再次进入

1. 分享入口显示权限范围和链接状态；复制成功、过期、撤销和无权限都反馈清楚。分享内容须说明谁可以查看/编辑及可访问素材范围。
2. 返回列表时不丢未保存状态；云端保存中离开需提示或等待可控保存完成。
3. 重进画布先恢复可见内容，再补充媒体和任务状态；显示“正在同步/已离线/保存失败”而非空白等待。
4. 发生版本冲突时保留本地草稿和云端版本，提供查看差异/保留本地/加载云端的清楚选择；不静默覆盖。

## 4. 按钮与控件逐项优化清单

以下每项均要求：名称能说明动作；禁用态有原因；忙碌态防重复提交；成功/失败有可见反馈；键盘焦点和读屏名称完整。图标按钮须有 tooltip 和可访问名称。

### 4.1 画布列表

| 当前入口/控件 | 建议体验 |
| --- | --- |
| 新建画布 | 主按钮固定在列表标题区；明确“新建画布”；支持回车；校验名称、取消和提交中状态；失败不清输入。空列表时同时提供同一主动作。 |
| 画布卡片 | 整卡可打开但卡内菜单独立；卡片显示标题、最近编辑、所有者/共享标识、封面状态；键盘 Enter 打开。 |
| 卡片操作菜单 | 菜单项按“打开/重命名/创建副本/删除”排序；当前用户无权操作时隐藏或禁用并说明原因；打开菜单后 Escape 关闭并还焦点。 |
| 重命名 | 对话框聚焦标题输入；显示当前名称；保存按钮随校验状态变化；相同名称不产生无意义保存；权限不足时解释并提供“创建副本”替代动作。 |
| 创建副本 | 菜单动作显示进行中；完成后提供“打开副本”快捷入口；副本标题自动去重且可再次重命名。 |
| 删除 | 确认对话框明确画布名、内容不可恢复及影响；危险主按钮标注“删除画布”；取消为默认焦点；删除中锁定重复操作。 |
| 分页 | 显示当前页/总页和总数；删除当前页最后一项后回到有效页；翻页保留列表滚动位置或回到网格顶部。 |
| 刷新/重试 | 加载失败保留旧卡片并在列表顶部显示内联错误与“重试”，不要仅 toast 后无恢复入口。 |
| 卡片封面 | 加载骨架、空封面、视频封面和加载失败统一；不因单张封面失败阻断列表；封面可访问名称包含画布标题。 |

### 4.2 编辑器顶栏和左侧工具

| 按钮/控件 | 建议体验 |
| --- | --- |
| 返回画布列表 | 明确未保存/保存中行为；有离开保护时说明正在保存或提供等待/继续离开；成功返回后列表位置与筛选状态可恢复。 |
| 画布标题 | 标题始终可见，支持就地重命名（如权限允许）；离开输入时保存，展示保存反馈；无权改名时仍可复制标题。 |
| 云端保存状态 | `已保存`、`保存中`、`离线`、`保存失败`带文字/图标和时间；失败状态可重试，悬停展示最后成功时间及错误摘要。 |
| 画布操作 | 菜单分组“创作/协作/帮助”；窄屏自动折叠；打开后焦点进入首项，Esc 关闭，选择后菜单收起。 |
| 剩余积分 | 显示余额和单位；点击后去充值/账单说明；余额加载失败或未知不显示为 0。 |
| 开始指南 | 首次进入可轻量推荐；完成/关闭后记忆状态；从此按钮再次打开。 |
| 导入文字或分镜 | 标注支持格式和导入后结果；解析前预览、节点数量/结构、覆盖风险；失败保留原文和映射信息。 |
| 教程 | 显示教程主题和预计时长；可关闭/恢复；教程高亮不遮挡真实控件、不夺走当前任务输入焦点。 |
| 分享 | 打开后先显示当前分享权限/链接有效状态；新建、复制、撤销分别有确认和成功反馈；分享权限变更说明立即生效。 |
| 添加 | 主入口菜单提供节点类型、描述、搜索和素材来源；最近使用优先；创建后关闭菜单并聚焦新节点。 |
| 拖动/抓手 | 文案改为状态语义（“框选”/“平移画布”或明确当前模式）；图标、激活态、状态提示一致；避免“拖动”含义不明。 |
| 锁定节点 | 当前名词容易误解按钮动作，建议按钮显式呈现“锁定节点”/“已锁定”；锁定后节点可选但不可移动，提示解除方式。 |
| 搜索 | 显示快捷键；搜索节点标题、文本、任务状态和类型；结果标注节点类型，选择后定位并聚焦节点；无结果可清空条件。 |
| 素材库 | 过滤当前工作空间和可用素材；预览、搜索、筛选、排序、批量选择；应用后说明新增了哪些节点。 |
| 历史 | 区分图片/视频、当前节点生成版本与画布变更历史；时间、模型/参数、当前版本明确；切换版本可撤销或确认。 |
| 帮助/快捷键 | 统一从工具栏和视图控制入口打开同一帮助；支持搜索快捷键；显示当前平台映射及输入框冲突规则。 |

### 4.3 画布视图控制和设置

| 按钮/控件 | 建议体验 |
| --- | --- |
| 缩小/放大 | 到达倍率边界后禁用；倍率变化以视口中心/指针为锚；连续按住可连续缩放；显示当前百分比。 |
| 缩放倍率 | 下拉预设、手动输入或点击回 100% 语义统一；支持 `适应画布` 单独按钮，避免把“复位视图”误解为回 100%。 |
| 适应画布 | 仅有节点时包含所有节点；空画布时回到默认中心；多选时可提供适应选区；不改变节点尺寸或数据。 |
| 网格吸附 | 使用“网格吸附”并显示开/关；拖动时视觉预览吸附结果；对齐辅助线和网格吸附的区别在设置中解释。 |
| 显示/隐藏连线 | 按钮标签随状态变为“隐藏连线/显示连线”，隐藏不影响真实依赖；连线被隐藏时给出持续状态标记。 |
| 小地图 | 开关状态清晰；小地图可拖动定位；遮挡内容时可收起、拖动位置；当前视口在地图中有足够对比。 |
| 界面大小 | 使用标准/较大/特大并即时预览；说明只影响画布控件；持久化当前用户偏好。 |
| 画布设置 | 分组“交互/外观/快捷键/通知”；每项说明影响范围；恢复默认需要二次确认或可撤销。 |
| 全屏快捷键模式 | 明确进入/退出与 Escape 行为；浏览器拒绝全屏时给出解释；不抢占地址栏等浏览器保留快捷键。 |
| 统计数字 | 节点、连线、失败计数可点击筛选/定位；失败数为 0 时不占视觉噪声；数字变化有读屏播报节流。 |

### 4.4 节点与上下文操作

## 5. 关键状态和反馈规范

### 5.1 列表与资源状态

| 状态 | 用户看到什么 | 可执行操作 |
| --- | --- | --- |
| 初次加载 | 页面骨架、标题和占位卡片 | 等待；避免全屏阻塞 |
| 空列表 | 解释此空间暂无画布，突出新建 | 新建、导入/从素材开始 |
| 列表刷新失败且有缓存 | 保留旧列表并标注数据可能较旧 | 重试刷新 |
| 无工作空间 | 明确需先选择/创建空间 | 前往空间切换 |
| 封面缺失/解析失败 | 稳定占位封面，不显示破图 | 打开画布 |
| 新建/复制/删除进行中 | 对应卡片/按钮忙碌，不重复执行 | 允许不冲突的其他卡片操作 |

### 5.2 画布保存与同步

- **已保存**：显示最近成功保存时间；不持续占据注意力。
- **保存中**：持续但轻量；关闭/返回策略明确。
- **离线**：说明本地改动仍保留、云端尚未同步；网络恢复后自动重试。
- **保存失败**：保留本地内容，提供重试和查看原因；不能把状态回落成“已保存”。
- **冲突**：保留双方版本，明确时间/来源，用户选择后才覆盖；选择前暂停危险的覆盖写入。
- **恢复草稿**：展示画布名、草稿时间和与云端差异；允许恢复或查看后放弃。

### 5.3 生成任务

提交前：模型目录就绪、输入校验、素材有效性、费用核验、权限确认、工作空间一致性。

提交后：幂等创建、任务 ID 与状态落盘、同任务恢复轮询、结果入库校验、媒体 URL 重新解析。

终态：成功显示可预览结果；失败保留输入/素材/原版本；取消不误删旧结果；状态未知时先查询原任务，不能默默重新创建付费任务。

### 5.4 破坏性操作与可逆性

- 删除节点：说明关联边/分组/后续引用的处理；源素材资产保留；支持撤销。
- 删除画布：强确认且说清不可恢复；执行前校验当前工作空间身份。
- 切换历史结果：保留当前结果为一个版本，明确撤销入口。
- 批量操作：在按钮上表达数量；执行前显示影响统计；部分失败时逐项列出结果。
- 导入覆盖：默认采用新增节点；若需要覆盖，必须逐项预览并显式确认。

## 6. 交互与视觉规范建议

### 6.1 层级

- **一级**：创作主动作（添加、生成、导出/合成）。同一面板只保留一个明显主按钮。
- **二级**：参数、模型、素材、分享等常用配置，使用清晰分组和状态摘要。
- **三级**：历史、详情、帮助、偏好、危险操作，置于菜单/抽屉，不抢占创作空间。

### 6.2 文案

- 按钮采用“动词 + 对象”，例如“添加图片”“重新生成”“下载源音频”“合成为视频”。
- 避免无对象的“确认”“确定”“完成”“拖动”等单词；对图标按钮提供动词 tooltip。
- 错误按“发生了什么 + 影响 + 下一步”书写，例如“素材读取失败，当前生成尚未提交。检查素材后重试”。
- 技术错误码仅作可复制的辅助信息，不替代用户可理解的解释。

### 6.3 动效与空间

- 节点创建、连线成功、保存成功使用短促、低干扰反馈；生成进度不使用无法解释的循环动画代替状态。
- 面板从边缘进入并保留画布上下文；遮罩只用于需要阻断的确认，不用于常驻编辑面板。
- 错误提示锚定受影响节点或操作区；全局 toast 只用于短暂确认，不承载唯一恢复入口。
- 浮动工具需考虑画布边缘、窄屏和浏览器缩放；小地图、节点面板和选区工具条不能遮住主结果。

### 6.4 可访问与输入设备

- 所有交互支持键盘焦点、焦点可见、合理 Tab 顺序和 Enter/Space 激活。
- 选择/弹窗使用正确对话框语义；打开后焦点进入，关闭后回原控件；Esc 规则一致。
- 状态不能只用颜色表达；生成、保存、选中、禁用均有文字/图标/读屏信息。
- 触控设备提供足够大的命中区和可见拖动句柄；关键功能不依赖悬停。
- 画布快捷键遵循 [无限画布快捷键](canvas-shortcuts.md)，输入框、媒体控件、浏览器保留快捷键优先级明确。

## 7. 全局动效语言

### 7.1 动效方向

动效主题定为 **“工作流有形、操作有回声”**：画布中的移动、连接和生成让用户看见关系与状态；常规控件快速响应，重要结果才使用稍长的完成反馈。避免全屏入场、连续弹跳、长期呼吸光效和为装饰而存在的粒子。

### 7.2 时间、缓动和属性

项目当前 `CanvasView.css` 已定义 `--canvas-dur-fast: 120ms`、`--canvas-dur: 180ms`、`--canvas-dur-slow: 260ms` 与 `--canvas-ease: cubic-bezier(0.22, 1, 0.36, 1)`。建议将其作为全画布默认动效 token，组件不再自行散落 `ease` 和相近时长；下表的时长以该系统为基准。

| Token/范围 | 建议值 | 使用场景 |
| --- | --- | --- |
| `--canvas-motion-instant` | 80–120ms | 按压、焦点、轻微颜色反馈 |
| `--canvas-motion-fast` | 120ms | 按钮 hover/pressed、选择状态、短提示淡出 |
| `--canvas-motion-base` | 180ms | 菜单开合、节点聚焦框、轻量状态切换 |
| `--canvas-motion-panel` | 220–260ms | 工具面板/抽屉进入退出；退出建议比进入快 |
| `--canvas-motion-spatial` | 260–360ms | 新节点落位、画布定位、视口适应等空间变化 |
| `--canvas-motion-result` | 360–520ms | 生成完成到结果卡片的单次呈现，不用于普通点击 |
| 默认缓动 | `cubic-bezier(0.22, 1, 0.36, 1)` | 跟手、减速收尾；与现有 token 一致 |
| 进入/退出缓动 | 进入使用 ease-out；退出使用更短的 ease-in | 关闭与删除反馈不拖沓 |

优先动画 `transform`、`opacity`、边框/背景色和局部描边。避免高频动画 `width`、`height`、`top`、`left`；画布节点移动由 React Flow 的视口/节点变换负责，不另叠 CSS 动画。阴影、滤镜、模糊和大面积渐变仅用于低频、局部状态。

### 7.3 减少动态效果

- 遵循 `prefers-reduced-motion: reduce`：取消位移、缩放、视差、循环脉冲和连续流动；用即时颜色/描边/图标/文案保留状态意义。
- 成功/失败等关键状态仍须可辨识，不能因关闭动画而失去结果确认。
- 生成进度在减少动态效果模式下改为稳定进度数值或阶段文字；无进度数据时使用静态“处理中”标签，不显示持续闪烁。
- 不播放交互音效作为唯一反馈；用户配置的提示音与系统静音偏好一致。
- 所有循环效果在任务结束、节点卸载、页面隐藏或离开视口时停止；重复触发需可立即中断并转入最新状态。

## 8. 逐事件动效规格

下表是待实施的目标规格。**已存在的效果**只表示代码中能找到相关动画/转场，不代表已满足建议的时长、手感或状态闭环。

### 8.1 入口、列表和导航

| 事件 | 动态表现 | 节奏 | 完成/中断规则 |
| --- | --- | --- | --- |
| 画布列表首次加载 | 卡片骨架淡入或静态占位，禁止每张卡片长距离逐个飞入 | 120–180ms；首屏最多短暂轻微错峰 | 已有缓存时直接呈现缓存，后台刷新只更新数据，不让整页闪白 |

## 9. 当前动效盘点与统一建议

当前 `CanvasView.css` 已有统一 token，以及交互提示、节点进入/选中、连线重复提示、参考素材选择、任务进度和连线状态等动画。若干组件也各自包含 toolbar、selection bar、drawer、preview、音频生成等转场，并有部分 `prefers-reduced-motion` 处理。

代码中仍能看到组件分别使用 `ease`、`ease-out`、`0.15s`、`0.22s` 等局部值。因此建议实施前按此清单盘点而非全量推倒重做：

1. **保留并校准**：节点/选区/抽屉/工具栏的现有动效，映射到统一 token，确定进入与退出方向。
2. **优先补齐**：拖动与连线的兼容目标、创建/删除/撤销、保存状态、任务结果切换、失败重试、时间线片段重排的事件闭环。
3. **降噪**：长时间无限脉冲、重复 shimmer、生成节点和边同时强动画；默认只保留一个主要活动提示。
4. **避免重复表现**：toast 与节点错误态不能同时闪烁；选中描边和搜索定位描边需有优先级；保存成功不与节点生成成功共用闪光表现。
5. **统一减少动态效果**：将每个画布 CSS Module 与 `CanvasView.css` 的 reduced-motion 规则纳入清单，确保无限循环、波纹、进度流和位移全部有静态替代。
6. **性能边界**：节点拖动/视口缩放期间不挂高成本滤镜；节点数较多时关闭非必要阴影/连线流动；动态效果只作用于发生事件的对象。

## 10. 动效设计验收

- [ ] 每个动效都能回答“用户做了什么、界面状态如何改变”；删除后若信息完全不损失，应删掉该动效。
- [ ] 点击反馈不阻塞操作；节点/画布拖动保持真实跟手；动画能被新的输入打断。
- [ ] 生成/保存/上传只展示真实状态，不用动画模拟进度。
- [ ] 创建、连接、删除、撤销、重做能让用户看清具体受影响的对象。
- [ ] 同一事件只出现一个主要反馈；没有 toast、描边、脉冲和工具条同时争抢注意力。
- [ ] 连续快速操作、任务轮询更新、页面切换和组件卸载不会残留定时器或循环动画。
- [ ] `prefers-reduced-motion` 下无大位移、缩放、视差、无限脉冲，状态仍可理解。
- [ ] 桌面鼠标、键盘、触控/窄屏均检查；高频拖动和大画布下无明显掉帧。
- [ ] 时长与缓动使用统一 token；局部例外有明确理由。

| 节点面板位置 | 桌面脚本面板位于视口偏下中央，尺寸较大，覆盖底部工具条和部分视图控制的可视区域 | 真实画面中面板遮挡了画布导航控件，打断“编辑节点后继续操作画布”的连续性；这比面板自身需要更强的入场动效优先级高 | 面板应与画布右侧/安全区建立稳定锚定，或打开时自动为工具条保留操作空间；动效只表达面板出现，不扩大遮挡范围 |
| 节点选中动效 | 浏览器断言检测到 `.react-flow__node.selected::after` 使用 `canvas-node-selection-ripple` | 这是可见的单次确认；被选中节点后续仍显示稳定描边，需留意波纹是否过强或与成功/错误提示混淆 | 将波纹限制为单次、低对比、短时反馈；减少动态效果时保留静态选中描边 |
| 左侧工具 hover | 工具标签显示在图标上方，位置与按钮中心对齐 | hover 标签能补足图标含义；当前依赖鼠标悬停的控件需确保键盘焦点也能显示标签 | tooltip 仅在 hover/focus 显示；动画采用短淡入；移动端提供可见标签或菜单文案 |
| 添加/连接节点 | 模拟流程验证了右键添加、左侧菜单创建、连接点语义以及连续创建下游节点 | 功能行为通过；现有流程断言重点在节点/边结果，未量化拖动中的动效帧率、命中目标高亮过渡和中断手感 | 后续动效验收需逐项实际拖拽，检查兼容目标高亮、非法连接收回、重复连线反馈和快速取消 |

### 11.3 观察结论与优先项

1. **先解决遮挡，再增强动效**：窄屏帮助浮球遮挡底部工具条；桌面节点面板遮挡画布底部工具/视图控件。空间关系稳定后再做面板和工具条过渡。
2. **为同一动作保留单一焦点**：创建节点时目前可同时出现选中波纹、面板出现和保存状态；目标规格应指定主次顺序。
3. **动效不能代替布局关系**：节点面板需要稳定锚定和明确可收起状态；用滑入效果无法补救控制被遮挡。
4. **当前验证范围是模拟接口交互**：它证明空画布和节点创建/连线的前端页面可运行，不证明实时模型、费用、任务进度、上传、保存网络抖动或音视频合成的真实时序。
5. **尚待观察的事件**：画布列表的创建/重命名/副本/删除；拖动、框选、缩放、小地图；面板/历史/素材抽屉开合；连接拖拽实时状态；生成成功/失败/重试；保存离线/恢复；音频试听与时间线合成。应在相应模拟流程中补截图或录屏，不把 CSS 源码推测当作浏览器实测。

## 12. 逐步落地优先级

### P0：可靠与可恢复（先做）

- 保存/离线/冲突状态统一呈现，并提供恢复和重试。
- 生成按钮状态、重复提交防护、原任务恢复、费用核验与失败归因。
- 删除/覆盖/历史切换的影响说明和撤销路径。
- 列表和画布空/加载/错误状态补齐可恢复操作。
- 核心按钮、图标按钮的名称、禁用原因、忙碌态和键盘焦点。

### P1：创作效率与可理解性

- 新手起步路径、添加菜单和节点说明优化；连接兼容性预览。
- 搜索、右键/快捷键/工具栏动作一致；多选操作显示明确数量与范围。
- 模型参数摘要、提示词引用、素材上传与结果历史更易读。
- 时间线顺序、音轨、试听、混音与合成进度清晰化。

### P2：高级体验与个性化

- 画布模板/工作流起步、最近使用节点、常用模型快捷方案。
- 大画布性能信息、失败聚合筛选、节点批量下载/导出管理。
- 用户可自定义工具布局、通知和快捷键；分享权限和协作状态增强。
- 新手引导基于真实行为逐步退出，而不是反复弹出。

## 13. 设计验收清单

### 入口与空状态

- [ ] 首次用户可以在不懂节点术语的情况下开始创作。
- [ ] 空画布至少提供脚本、输入想法、添加素材、导入四种明确起点。
- [ ] 列表新建、打开、重命名、副本、删除、分页和失败重试都有清晰结果。
- [ ] 带入素材在创建画布后仍可完整抵达节点。

### 编辑与导航

- [ ] 框选、平移、节点拖动、锁定、连线、删除、撤销/重做相互不冲突。
- [ ] 缩放、适应画布、小地图、网格/对齐、隐藏连线的状态可见且不误操作。
- [ ] 搜索、右键菜单、快捷键、工具栏对同一动作给出一致名称和结果。
- [ ] 多选/分组/整理/批量下载明确操作范围，且可恢复。

### 生成与素材

- [ ] 模型、参数、参考素材和费用核验状态可理解。
- [ ] 输入锁定、提交中、处理中、失败、成功、任务恢复状态明确。
- [ ] 失败后仍保留提示词、参考素材、参数和原结果；重试不会误重复付费。
- [ ] 结果可预览、下载、查看历史、切换版本并连接到下游。

### 音视频交付

- [ ] 时间线片段顺序、时长和音轨作用可见；试听与视频同步。
- [ ] WAV 与 MP4 导出内容差异清楚；合成过程和限制透明。
- [ ] 输出结果成为新节点，不覆盖源素材；失败后可继续编辑与重试。

### 保存、分享和可访问性

- [ ] 保存、离线、失败、冲突、恢复状态有完整反馈和明确操作。
- [ ] 分享权限/链接状态可读，复制、更新、撤销有反馈。
- [ ] 所有图标按钮有可访问名称；弹窗焦点进出正确；键盘操作可完成主流程。
- [ ] 桌面、窄屏和触控布局中，核心操作不被工具条/小地图/抽屉遮挡。

## 14. 当前能力与建议的边界

当前实现已覆盖画布列表管理、节点工作流、多种媒体生产与编辑、历史、快捷键、视图偏好、分享、保存、任务恢复等多个模块；这是功能面梳理，不代表所有模型、后端接口、浏览器编码器或权限组合均可用。

本蓝图重点补足体验连贯性和状态表达。正式实施前应逐项标记：**已有且体验达标 / 已有但需优化 / 后端或模型依赖 / 需新增能力 / 暂不开放**。对于音频、高清、真人素材、分享和生成费用，应以当前空间真实目录和后端契约为准；不要在界面方案中承诺前端无法保证的行为。
