# 画布声音样本 P0 实现说明

## 已实现

- 音频生成面板新增“声音样本库 / 视频提取”入口。
- 100MB、5 分钟内普通 MP4/MOV/M4V 视频先提取音轨，再由浏览器解码。
- 用户选择 5～30 秒片段，试听、命名、确认使用及克隆授权后导出单声道 PCM16 WAV。
- WAV 通过现有素材上传接口入库，写入节点 audioReferences，可供现有支持参考音频的模型使用。
- 当前账号、当前工作空间隔离的本机收藏：名称、搜索、试听、最近引用排序、一键引用和移除。
- 库只保存 assetId、名称和最近使用时间，不保存播放地址、PCM 或原视频。
- 引用前验证素材仍属于当前空间且可用；上传沿用模型 MIME、大小和数量约束。
- 新面板延迟加载，无新增第三方依赖。
- 当前工作空间没有音频模型时，明确提示可切换到已开放音频模型的空间或联系管理员。

## 限制

- 这是声音参考样本库，不是训练后的独立音色库，不生成 voice_id。
- 不保证分离多人声、去除背景音乐或保持跨镜头声音绝对一致。
- 暂不支持 WebM、分片 MP4 和浏览器无法解码的音频编码；失败需用户转换或直接上传音频。
- 同意授权仅为前端声明，不代表完成服务端审核。
- 收藏仅当前浏览器可见；清除站点数据会丢失收藏，但不会删除服务端素材。
- 引用不自动启动收费生成，现有克隆授权及费用确认仍生效。
- P1 角色绑定、音画任务编排及 P2 变速、人声分离本轮未实施。

## 验证

- 54 项声音样本和既有音频回归测试通过。
- 新工具覆盖率门槛通过：voiceSample 分支 80.55%，voiceLibrary 分支 86.95%。
- 应用及测试类型检查、本次变更严格 lint、生产构建通过。
- 包体策略未通过：总 JS gzip 1055.63 KiB，门槛 1024 KiB。试验分包均未达标，已恢复原构建配置，未放宽门槛。
- 88 项样本提取、引用、混音和视频播放同步回归测试通过。
- 真实 Chrome 验证通过：浏览器编码的 AAC 音轨提取后解码约 6.016 秒，截取并重新解码 WAV 为 5 秒、240044 字节，RMS 约 0.1414，确认不是静音；无音轨视频正确报错。这是合成音频测试，不代表真实人声克隆质量验收。
- 后续已有有效登录态，当前画布为 /canvas/108，网络请求显示工作空间为 2。音频目录接口返回 HTTP 200、data: []，无法继续调用克隆模型。
- 真实样本上传、克隆新台词及最终配音成片导出仍未完成端到端验收。

## 真实素材验收

上传清晰单人声视频 -> 选取样本并试听 -> 上传 -> 调用支持参考音频的克隆模型生成新台词 ->
刷新并重新引用收藏 -> 给无声视频配音 -> 导出 MP4，确认声音、时间位置与试听一致。

- 从视频提取后上传前要求选择支持参考音频的模型；仍沿用 WAV 格式约束。
- 上传期间禁止切换模型和模式，数量限制读取节点最新参考列表。
- 样本提取、收藏和生成面板定向回归测试 40 项通过；应用及测试类型检查和相关文件严格 lint 通过。
- 前端操作码识别组件测试确认 `audio.text_to_speech` 显示为配音、`audio.generate` 显示为音频生成；不产生收费请求。
- 实际目录查询已确认个人空间 2 只有图像模型；技术部空间 11 提供 TTS 和音频生成模型；所查空间均未发现 `audio.clone`。

## 后端联调核对项

已测当前空间接口（均返回 200、空列表）：

```text
GET /api/v1/ai/models?workspace_id=2&operation_code=audio.clone
GET /api/v1/ai/models?workspace_id=2&operation_code=audio.tts
GET /api/v1/ai/models?workspace_id=2&capability=audio
```

前端实际调用 listAiModels 时显式设置 plan: ''，不发送默认 pro 套餐筛选。
空目录不能单独证明“没有部署模型”，也可能是空间授权、操作码登记或 capability 分类不匹配。

已使用完整模型目录和空间列表做过对照：

```text
GET /api/v1/ai/models?workspace_id=2
# 个人空间：仅 image.face_detect

GET /api/v1/ai/models?workspace_id=11
# 技术部：Seed TTS 2.0 (audio.text_to_speech)、Seed Audio 1.0 (audio.generate)
```

完整目录确认不存在 operation_code 为 `audio.clone` 的模型。技术部空间 11 的 Seed TTS 2.0 有公共 speaker ID 参数；Seed Audio 1.0 声明可接收最多 3 个 audio 参考，但这不等于后端提供独立的音色训练/克隆 API，也未验证参考样音是否会作为文本配音音色使用。

若需进一步诊断后端目录，再对当前空间查询不带 capability、operation_code、plan 的模型列表：

```text
GET /api/v1/ai/models?workspace_id=2
```

若完整目录存在音频生成模型而 capability=audio 查询缺失，需要修正后端能力分类或有证据后调整前端查询；
个人空间 2 的完整目录已确认没有音频生成操作，需后端为该空间开放模型，或用户切换到具备模型的空间。前端识别音频产物目录中的 `audio.text_to_speech` 与 `audio.generate`，已补组件回归覆盖。

## 当前可用路径

- 若目标是使用平台公共音色生成配音并混入视频，可切换到技术部空间 11 使用 Seed TTS 2.0；使用前需确认该空间模型权限与实际费用。
- 若目标是把提取的声音样本用于克隆新台词，当前全部已查空间均没有独立 `audio.clone` 操作。Seed Audio 1.0 虽接受音频参考，但不能据此承诺它支持音色克隆；需要后端确认用途与提交契约。

克隆模型可用后核对：

- 目录声明真实 operation_codes 和可提交的模型版本 ID，不能由前端猜测。
- input_constraints 对应操作声明音频 role、数量、WAV MIME 和大小限制。
- 确认 PCM16、单声道、24000 Hz WAV 是否支持，以及参考样本 5～30 秒是否符合模型要求。
- params_schema 提供必填参数和默认值；明确是否还需要样音对应的原始转写文本。
- 明确 audio.clone 输出是新台词音频资产还是 voice_id；目前前端仅接收音频成品，不能直接兼容仅返回 voice_id 的训练接口。
- 真实生成前确认费用，再使用取得授权的清晰单人声素材进行质量验收。

## 2026-10-20：服务端音色库接入

### 2026-10-22：我的音色添加入口

- 画布音色库的“我的音色”页签提供“添加音色”，复用现有录音上传、声音样本选择、授权确认和创建接口。
- 空间所有者或管理员可创建；普通成员显示禁用入口及联系管理员的说明。系统音色与收藏页签不显示添加入口。
- 创建提交后返回“我的音色”，清除搜索与筛选并关闭模型兼容筛选，便于看到尚在训练、未成为模型可选项的新音色；界面明确区分“请求已提交”与“音色可选用”。
- 该入口不同时开放编辑、删除、重试训练等其他管理操作。真实训练会使用空间预付费音色槽位；自动化验收仅模拟创建请求，不消耗真实训练次数。

以上关于独立音色接口缺失的描述是旧环境核查结果。新版契约来源：
`http://124.174.95.225:9000/swagger/doc.json`，提供 `/api/v1/voices` 系列 9 个用户端操作。

- `src/api/voices.ts` 对接列表、创建、详情、编辑、删除、收藏、取消收藏、重试和同步；全部携带 `workspace_id`。
- 音频节点“音色库”默认打开在线音色；列表支持模型兼容性、来源、个人收藏、语种、关键词和分页筛选。关闭兼容筛选后用于管理，选用需开启兼容筛选并先选择模型。
- owner/admin 使用预付费槽位创建音色。样本先上传为资产，支持 WAV/MP3/OGG/M4A/AAC，最大 10 MiB。表单确认授权后提交 `sample_asset_id` 和 `idempotency_key`；同一次表单重试保留上传结果与幂等键。
- 音色训练与配音生成分开；选用后以 `params.voice_id` 接入报价和生成，生成前重新查询可用状态。更换模型需重新选择兼容音色。
- 处理中音色每 10 秒最多同步当前列表中的 5 条，页面隐藏时暂停；支持手动同步试听地址。关闭界面不代表服务端训练取消。
- 删除不会回收槽位，也不会删除供应商记录或历史配音素材；界面提供二次确认。
- 本机声音样本仍是按账号和空间隔离的资产收藏，不是服务端音色；可作为创建音色的录音来源。
- 本地开发代理通过 `.env.local` 的 `ZZH_REMOTE_ORIGIN` 配置，修改后需重启 Vite。代码没有硬编码业务接口主机。

验证范围：接口契约测试、组件测试和使用模拟响应的浏览器布局检查。真实账号、预付费槽位、训练质量及真实配音产物仍需在新环境登录后联调；自动化检查不占用真实训练次数。

### 2026-10-22：明确复刻供应商及录音校验

- 新建默认 MiniMax，表单可切换火山引擎；创建请求显式发送 `provider`，不依赖服务端火山默认值。
- MiniMax 本地上传限制 MP3/M4A/WAV、20 MiB，上传及创建前通过音频元数据检查 10～300 秒；本机资产样本通过同源试听读取时长，素材格式、大小与权限仍由后端最终校验。
- 元数据未读取、无法播放或时长不合规时禁用提交，5 秒录音会显示明确提示。切换样本或供应商需要重新确认授权。
- 火山继续使用 10 MiB 限制及预付费槽位。MiniMax 无需槽位，7 天内首次合成激活并产生音色费用；真实训练与付费合成未由自动化测试执行。
- 相同输入失败重试保持原幂等键；提交后改变名称、录音或供应商视为新的创建输入，生成新键。

### 2026-10-22：现场录音与统一最低时长

- “我的音色 → 添加音色”支持现场录音：主动请求麦克风权限、3 秒倒计时、真实音量显示、停止、试听、重录和采用。最长录制 60 秒，建议 20～30 秒；不足 10 秒允许试听但不能采用。
- 上传录音和已有声音样本统一校验实际时长至少 10 秒，保留供应商的格式、大小和最长时长限制；未读到时长、无法播放或元数据读取超时均不允许提交。明确展示上传最低时长提示。
- 浏览器录音解码为 24kHz 单声道 PCM16 WAV，并进行基础静音检查；不调用转文字接口，不自动上传或创建音色。采用后须确认声音授权，提交复用现有资产上传、音色创建与幂等键链路。
- 等待授权时可取消；迟到授权立即释放。停止、取消、卸载与设备中断清理采集流、计时器和音量分析器。切后台结束当前录音；返回后不自动续录。
- 录音期间禁止切换样本及提交；未采用的录音草稿不能用于提交。取消表单或关闭音色库会确认丢弃未提交录音；刷新通过浏览器离开提示保护，录音不写入本地持久存储。
- 创建权限和空间隔离沿用既有规则。前端最低时长校验不替代服务端音频检查；服务端规则及真实麦克风、训练质量与付费合成仍需真实环境验收。
