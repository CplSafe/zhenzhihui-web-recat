# 剧本创意原型流程核对

参考：`F:/工作文件/剧本创意C端原型.html`。用户明确要求删除首页“创作流程”、面包屑、详情标题卡、详情侧栏“这一步要交什么”、进度中的入驻、刷新进度及指定提示；这些要求优先于原型截图。

| 环节 | 原型字段 / 页面 | 状态与动作 |
| --- | --- | --- |
| 入驻 | 当前账号；真实姓名、身份、学校、手机、邮箱、擅长题材必填；年级、城市、微信选填；同意声明 | 入驻后可修改；入驻是账号资料，不算创意任务。未登录点击入驻时需先确认，再跳登录。 |
| 提交创意 | 申请人和学校由入驻资料带入；剧名、题材、剧情简介、剧本文档附件必填；第一集剧情和人物设定选填 | 提交进入审核中；审核中只读，可撤回；被打回后按意见修改并重新提交；通过后可继续一卡。 |
| 一卡 | 中文剧名继承创意；英文剧名、覆盖集数、免费段最强付费卡点、完整版简介、核心卖点、人物小传、分集大纲与付费卡点及一卡附件必填 | 具备待提交、审核中、撤回、需修改、已通过；通过后进入剧本。 |
| 剧本 | 剧名、题材继承；预计集数、单集时长范围、首个付费解锁集、分幕大纲和完整剧本附件必填；付费节点数和世界观规则选填 | 提交后进入审核，审核通过后进入完善剧本。 |
| 完善剧本 | 显示评审意见；修改说明、终稿附件、原创声明必填 | 审核通过后全流程完成，终稿只读；被打回可修改重提。 |
| 我的创意 | 搜索剧名、编号、申请人，按阶段、审核状态、题材筛选；展示四项统计、表格与分页 | 入驻不生成任务；状态文字应反映任务真实状态；用户要求移除身份筛选。 |

附件原型限制：最多 30 个，每个最大 500 MB；支持 doc、docx、pdf、txt、md、ppt、pptx。模板按阶段下载。原型本身的模拟审核不代表后端审核。

当前实现的本机演示和真实申请分别保存；本机模拟记录的列表、筛选和统计不代表服务端结果。正式服务端接口尚缺独立创作者档案、附件、四阶段字段及列表统计筛选契约，不能将本机模拟状态写作真实审核状态。
