# 无限画布快捷键

在画布工具栏点击「快捷键」，或在输入框外按 `?` 打开说明。按 Esc 或点击遮罩关闭。
系统自动识别：Windows / Linux 使用 Ctrl、Alt；Mac 使用 ⌘、Option。

| 操作 | Windows / Linux | Mac |
| --- | --- | --- |
| 成组 | Ctrl + G | ⌘ + G |
| 解组 | Ctrl + Shift + G | ⌘ + Shift + G |
| 合并为视频剪辑 | Ctrl + Alt + G | ⌘ + Option + G |
| 连线 | L | L |
| 复制 / 粘贴 | Ctrl + C / V | ⌘ + C / V |
| 创建副本 | Shift + D | Shift + D |
| 拖拽复制 | Alt + 拖拽节点 | Option + 拖拽节点 |
| 生成 | Ctrl + Enter | ⌘ + Enter |
| 放大 / 缩小 | E / Q | E / Q |
| 适应画布 | 1 | 1 |
| 搜索 | Ctrl + F | ⌘ + F |
| 撤销 | Ctrl + Z | ⌘ + Z |
| 重做 | Ctrl + Shift + Z / Ctrl + Y | ⌘ + Shift + Z / ⌘ + Y |
| 整理画布 | Alt + Shift + F | Option + Shift + F |

两种系统共有：N 添加节点，Tab 保留焦点导航；V 选择工具；H 抓手工具；Space + 拖拽、中键拖拽、右键拖拽平移画布；W/A/S/D 键盘平移，Shift 加速；E/Q 放大缩小；0 回到 100%；1 适应视图；方向键微移节点；F2 重命名；Delete 或 Backspace 删除。

成组至少选中两个节点。连线需要选中两个节点，按选择顺序从第一个连接到第二个，沿用类型、重复连线及循环校验。合并为视频剪辑沿用现有可用视频筛选与时长限制，不是自动生成视频。整理时多选只整理选区，否则整理全画布。

生成快捷键用于已经打开的节点面板，在输入框外使用；按钮被禁用时不会提交。输入框内保留文字编辑快捷键。点击画布后快捷键才生效；点击画布外区域、进入输入框、按钮、媒体或弹窗时暂停接管。Ctrl/⌘ + L、D、加减号和 0 保留浏览器的地址栏、收藏与页面缩放行为。只有存在可用操作时才接管成组、撤销、复制等快捷键。设备系统识别决定显示文案，不区分物理键盘品牌。
