# 无限画布高清处理：前端实现与待接入协议

2026-10-20。依据用户提供的 `PRD-无限画布视频超分与图片超清-v1.0.md` 与 `index2.html`。

## 当前边界

读取当前业务环境 Swagger 后，未发现超分/超清接口。以下 `/api/v1/ai/hd` 路由是**待后端评审实现的协议，非现有接口**。前端收到 404/501 会显示服务未接入并禁用提交，不调用通用生成接口代替超分，不使用原型假价、模拟进度或本地扣费。

已实现：单节点、多选、整组入口；图/视频分流；逐条校验与跳过原因；共同目标档位；报价与余额拦截；原子批量提交客户端；任务面板筛选/50条分页/统计；排队取消、失败重新报价；同步视频对比与可调分屏；独立结果节点、来源连线和持久化。真实供应商、扣退积分、跨端去重和后台结果交付必须由后端实现后联调。

## 统一约定

- 所有接口使用现有 cookie 鉴权，校验 workspace 成员身份、画布权限和素材访问权。响应可直接为对象或放在 `data` 下。
- 任务 ID 为稳定字符串，状态仅 `queued/processing/completed/failed/cancelled`。
- 源信息为 `{node_id,asset_id,kind:'video'|'image',name}`。标题用于展示，不参与能力判断。文件为 0 的源件也必须返回跳过原因，例如“请先生成成片”。
- 真实来源、宽高、时长、帧率、格式、文件存在性由服务端探测/读取素材元数据；不可相信前端传来的模型名称或规格。
- 时间为 ISO 8601；积分为现有账本相同单位的非负有限数字；前端不换算新单价。
- 输入源件快照固定为素材 ID，生成新视频或替换图片后，旧报价不可悄悄绑定到新文件。

## POST /preflight

请求：`{workspace_id,canvas_id,sources:HdSource[]}`。

响应：`{items:HdItem[]}`，必须与输入逐项一一对应，包含原 source 的四个字段以及：

```json
{
  "eligible": true,
  "reason": "",
  "source_spec": "480P · 5s · 24fps",
  "resolutions": ["720P", "1080P", "2K"],
  "frame_rates": [60, 90]
}
```

`resolutions` 由低到高，仅返回真正高于源规格且供应商支持的档位；`frame_rates` 仅返回允许提升的目标帧率，图片返回空数组。无需调整帧率统一用 `fps:0`。当前前端排除 30fps。图片尺寸档位含义由能力侧统一定义，不能按文件名推断。

不可处理项 `eligible:false` 并给出白话原因：最高档位、来源不支持、源文件删除、超时长、已有在途任务、素材未产出等。支持范围、格式、时长以真实能力决定，不写死原型的 4K/一分钟。

混合类型先由前端分流。批量取所有可处理条目的目标交集，默认最低共同档；无共同档时不下单，提示拆批。跳过条目不参与报价。

## POST /quotes

请求：`{workspace_id,canvas_id,sources:HdSource[],target:{resolution,fps}}`。

响应：

```json
{
  "quote_id": "opaque-id",
  "expires_at": "2099-01-01T00:00:00Z",
  "items": [{"node_id":"video-1","asset_id":10,"credits":12}],
  "total_credits": 12,
  "balance": 100,
  "can_afford": true,
  "estimated_time": "1～3 分钟",
  "fps_multiplier": 1.5
}
```

报价绑定 workspace、画布、素材快照、真实能力版本、目标参数和逐条金额。总价等于逐条报价之和；补帧费用已包含在金额中，`fps_multiplier` 只用于展示，前端不再乘。未提供真实耗时则不显示假区间。更改目标后旧报价立即失效；失效、缺项、重复项或合计不符均禁止提交。

## POST /batches

请求：`{workspace_id,canvas_id,quote_id,idempotency_key}`。

响应：`{tasks:HdTask[]}`。

必须在事务内重新校验报价、源件、权限、在途任务、余额，再冻结合计积分并创建所有子任务。校验失败整批不创建、不冻结；不得让浏览器循环单条提交来模拟原子下单。执行阶段各条独立排队与结算，失败不影响同批其余条目。

同一 workspace + 幂等键重试必须返回同一批任务；响应丢失后重试不得再收费。前端在当前确认弹窗保留幂等键；未知提交结果时锁定参数/重新报价，只能重试原请求或查看任务台。跨刷新、跨标签页还必须按源节点+素材建立服务端在途唯一约束，preflight 返回处理中原因。

确定未创建的 400/402/403/409/422 返回清晰中文原因；报价过期、价格变化或余额不足时，前端要求重新报价确认，不能按变更后的价格静默下单。

## GET /tasks

查询：`workspace_id,canvas_id?,kind?,status?,keyword?,limit=50,offset`。

`keyword` 对任务 ID/源文件名不区分大小写。结果按提交时间倒序，返回：

```json
{
  "items": [],
  "total": 0,
  "stats": {"total":0,"active":0,"completed":0,"failed":0,"refunded_credits":0},
  "canvases": [{"id":3,"name":"第一集"}]
}
```

统计为当前 workspace 的汇总，不依赖分页。行完整类型见 `src/api/canvasHd.ts` 的 `HdTask`。必需信息：所属空间/画布、源信息、源规格、目标、状态、服务端真实阶段、起止时间、积分、失败原因、独立退分状态和实退金额。

`refund_status:none/pending/refunded`；不能将失败/取消直接等同于已经到账。任务失败/取消后按照现有账本规则逐条退回，只有到账后返回 `refunded`。

前端后台按当前画布分页读取，每8秒串行同步；任务面板独立拉取筛选页。404/501 停止后台探测，用户重新操作可重试。后续可换成增量游标或事件订阅，不改变 UI。

## POST /tasks/{id}/cancel

请求：`{workspace_id}`；响应：`{task:HdTask}`。

服务端原子校验仍处于 queued 才能取消并发起退分；已经 processing 时返回冲突且不能取消。前端弹出二次确认，不能先改本地状态冒充取消成功。

重试没有“恢复旧任务”操作：前端重新校验原文件、回填原目标、重新报价与确认，创建新的任务/账单，旧终态保持不动。原参数不再支持时明确提示改选。

## 结果与画布回写

成功 `result`：`{asset_id,name,spec,width,height,review_policy,canvas_delivery}`。必须先完成素材入库，再发布 completed，实际扩展名、规格与命名均以输出为准。`review_policy:reuse_source` 才显示“审核复用源件”，其他策略只显示真实审核状态。

后端统一分配 `-HD/-HD2/...` 名称，输出入“我的素材”，来源为“高清处理”，账本流水关联任务 ID。

当前前端用 `hd-result-{taskId}` 与 `hd-lineage-{taskId}` 固定 ID 写入现有增量保存链路。节点存 assetId 和轻量 hd 来源数据，不持久化签名 URL。谱系边使用现有 `provenance:true`，不参与生成输入。结果普通 image/video 节点；源件、既有结果及下游时间线不修改；新节点保留原选区并自动避让。

`canvas_delivery:pending/attached/removed` 必须由服务端根据画布元素和 tombstone 判定。removed 不再次创建；attached 的已删除结果不得被后台重新写回。前端还维护本会话已交付任务集合，避免重复轮询、用户删除或撤销后重新建节点。任务与结果关联不可因为打组/解组丢失。

页面关闭后的任务由后端继续处理；下一次打开画布，前端从任务列表恢复结果。若要求无人打开画布也立即落节点，由后台按上述固定 ID 写元素并推进 revision；前后端不得各自分配结果 ID。服务端必须保留删除 tombstone，避免同步冲突使用户已删除的结果复活。

源节点删除不删除任务/产物：当前通过任务台仍可查看对比和下载，不复活源节点。“主动添加到画布”作为后续交互扩展。对比源文件不可用时显示加载错误，高清版仍可下载。

## 联调与验收

1. 真实 480P → 支持的高清档位；输入输出内容一致、时长/音轨保留、分辨率与帧率符合实际。
2. 混选分流、全跳过、无共同档、余额不足、价格变动、过期报价。
3. 连点、网络响应丢失、刷新重试、多端同时发起不重复扣费。
4. 批量单条失败/超时独立退分；排队取消与开始处理的竞态。
5. 关闭页面后恢复、跨空间隔离、源节点删除、结果删除后刷新不复活、多人 revision 冲突。
6. 新结果、新素材、谱系标记持久化；原文件、下游引用与原生成状态不变。
7. 新失败重试任务重新计价；源片/高清版同步对比、下载实际格式。

AI 审查记录另行立项，目前任务台入口明确禁用。演示控制台、假价、模拟成功/退分不进入产品。
