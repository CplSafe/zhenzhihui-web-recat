## 尚需继续落地

- 三种玩法的独立参数面板、菜单第五项顺序、四种创建入口完整验收。
- 音视频分离：提取独立音轨、生成无声视频、上传新资产并创建两个节点；保护源文件。
- 音色训练与可复用音色库：需要样音提交、音色 ID、训练状态、授权记录保存及删除引用检查接口。
- 可商用曲库：需要授权曲目目录及授权字段，不能把普通上传音频标记成可商用曲库。
- 素材删除引用提示、删除后节点占位、素材页面音色管理。
- 节点级输出规格、预计时长、生成前报价回显、时长超限改写建议。
- 音频与视频引用语义及连线矩阵完整验收；此前按用户要求开放的音频→音频参考连接需要按最新一期范围统一。
- 文件级 AIGC 标识、授权样音审计、导出后素材入库、只读分享音频验收。

已知后端契约：通用模型目录、预估、任务提交/查询及素材接口。当前读取的 Swagger 未列出独立音色训练、音色目录、授权曲库接口。音频生成的实际能力仍由当前工作空间的模型目录决定。

## 2026-10-12 LibTV 音频生成流程补齐

- 音频节点继续只显示波形、播放和时长；选中后在下方显示独立白色生成面板。
- 参考音频支持上传、试听、移除；根据当前模型 input_constraints 决定入口可用性和提交 role。引用只保存 assetId、workspaceId 和标题，随画布保存，并纳入素材引用收集。
- 文字输入支持展开/收起；模型参数继续读取真实 params_schema。模型目录提供刷新入口。
- 费用预估与正式提交复用相同参数和参考素材校验；预估不创建任务。修改文案、模型、参数或参考素材后清除旧报价，并忽略过期异步结果。
- 生成任务进度从后端轮询获取；保持恢复已有任务的逻辑。已有音频可重新生成，历史版本入口移到面板顶部，任务进行中禁止切换结果。
- 历史回放、波形试听、源音频下载、裁剪与音量设置 WAV 导出沿用已有实现。
- 本次没有取得 LibTV 登录页面的浏览器连接，依据此前记录实现，未声称完成实时对照或付费生成验收。
- 尚未实现：LibTV 实时界面逐项核对、@ 引用语法、完整模型菜单视觉对齐、变速/智能切分、独立音色训练、真实配音端到端生成。帧智汇当前账号的目录只有语音识别模型，仍需后端开放音频生成能力。

## 2026-10-12 音频流程校验与玩法区分

- 当前模型目录若提供多种音频生成操作，面板按配音、音乐、克隆等真实操作分组选择；切换玩法时清除旧模型及旧参数，避免跨模型误提交。
- 配音、音乐和克隆分别给出对应的文案提示；模型参数仍由后端 schema 决定。
- 预估和提交前检查参考音频仍在当前工作空间的有效音频素材列表中，失效时在扣费前提示重新选择。
- 视频生成面板提示音频连线是模型参考；需要确定混入成片时应接入视频剪辑节点音轨。
- 尚未完成当前账号的真实付费生成验收：实际目录需先返回可输出音频的模型与操作码。

## 2026-10-15 LibTV 功能文档对照

- 文案输入 `@` 时列出当前画布、当前工作空间内已入库的音频；选择后作为参考音频关联，检索文字不写入生成文案。提交前继续按模型输入约束检查并核验素材有效性。
- 当前后端支持批次任务，但画布音频节点仍只持久化一个任务 ID 和一个结果。批量生成需先补齐多任务轮询、费用与多结果展示，暂不显示会丢失结果的数量控件。
- Seed Audio 的输出格式、语速、声调、音量仅在当前工作空间模型 schema 声明对应字段时开放；不硬编码文档中的默认值。
